# 读书的意义

有人说，书是人类进步的阶梯。这句话虽然简单，却道出了读书的真正意义。

读书最直接的好处，是获得知识。通过读书，我们可以了解几千年前的历史，可以看到几万公里以外的世界。一本好书，就像一位老师，把前人的经验和智慧交到我们手里。如果不读书，我们的见识就会被限制在自己生活的小圈子里。

读书还能改变一个人的气质。俗话说"腹有诗书气自华"。书读得多了，说话做事自然就不一样。遇到问题的时候，读过的书会给你提供不同的角度；和人交流的时候，你也会有更多的话题。这种由内而外的变化，是任何外表的打扮都代替不了的。

当然，读书也要讲究方法。不是读得越多越好，而是要读好书、会读书。读的时候要思考，读完以后要运用。否则，就算读了再多的书，也只是一个书呆子。

在我看来，读书是成本最低的投资。花几十块钱，就能和世界上最聪明的人对话。这笔生意，怎么算都是值得的。

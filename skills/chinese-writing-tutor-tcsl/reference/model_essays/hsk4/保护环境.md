# 保护环境

现在，环境问题越来越严重，已经影响到了我们的日常生活。保护环境，不只是政府的事，也是我们每个人的责任。

首先，我们要节约用水。洗脸刷牙的时候，不要让水一直流着。洗完衣服的水，可以用来冲厕所。

其次，要减少垃圾。买东西的时候，自己带袋子，少用塑料袋。没用的纸和瓶子，可以回收再利用。

还有，我们要多种树。树可以让空气变干净，也可以让城市变漂亮。

虽然我们每个人能做的事情不多，但是如果大家都行动起来，环境一定会越来越好。保护环境，就是保护我们自己的家。

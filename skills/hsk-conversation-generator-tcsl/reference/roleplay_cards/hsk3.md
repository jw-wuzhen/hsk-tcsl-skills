# HSK3 角色扮演任务卡（4个）

本文件为角色扮演任务卡的参考样例。每张卡：情景 + 角色A/B + 任务目标 + 语言要求 + 参考表达 + 表演时间。生成新任务时按该等级语言边界设定“语言要求”与“参考表达”。

## 1. 《租房看房》（日常生活>日常事务）

**情景**: 你去看一套房子，房东带你参观

**角色A**: 你：看房的人

**角色B**: 房东

**任务目标**: 了解房子情况，商量价格，决定租不租

**语言要求**:
- 问房子大小、设施
- 问租金和费用
- 用“虽然……但是……”说一个看法

**参考表达**: 这套房子怎么样？ / 一个月多少钱？ / 包括水电费吗？ / 有点小/不错。 / 可以。

**表演时间**: 5-8分钟

---

## 2. 《去商店换衣服》（日常生活>购物）

**情景**: 你昨天买的衣服太小了，去商店换

**角色A**: 你：顾客

**角色B**: 店员

**任务目标**: 成功换到合适的衣服

**语言要求**:
- 说清楚问题
- 出示收据
- 试穿新衣服

**参考表达**: 我想换一件…… / 请把收据给我看看。 / 这件刚好。 / 可以。

**表演时间**: 5-8分钟

---

## 3. 《向老师请假》（教育情况>校园生活）

**情景**: 你生病了，要去办公室向老师请假

**角色A**: 你：学生

**角色B**: 老师

**任务目标**: 请到假，安排好作业

**语言要求**:
- 说明请假原因
- 问作业怎么办
- 感谢老师

**参考表达**: 老师，我想请假。 / 我感冒了。 / 医生让我休息。 / 作业怎么办？ / 谢谢老师。

**表演时间**: 4-6分钟

---

## 4. 《请朋友吃饭》（日常生活>饮食）

**情景**: 你请朋友来家里吃饭

**角色A**: 你：主人

**角色B**: 你的朋友

**任务目标**: 让朋友吃得开心，朋友夸你的手艺

**语言要求**:
- 用“别客气”
- 介绍你做的菜
- 朋友用“真好吃”夸奖

**参考表达**: 请进，请坐。 / 别客气，多吃点。 / 这个菜真好吃！ / 是我做的。 / 尝尝汤。

**表演时间**: 5-8分钟

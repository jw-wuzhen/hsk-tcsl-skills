# HSK1 角色扮演任务卡（4个）

本文件为角色扮演任务卡的参考样例。每张卡：情景 + 角色A/B + 任务目标 + 语言要求 + 参考表达 + 表演时间。生成新任务时按该等级语言边界设定“语言要求”与“参考表达”。

## 1. 《认识新朋友》（基本信息>个人信息）

**情景**: 开学第一天，你在教室里第一次见到新闻学

**角色A**: 你：新来的学生

**角色B**: 你的新闻学

**任务目标**: 互相认识：问名字、问国籍，说“很高兴认识你”

**语言要求**:
- 至少互相问3个问题
- 用完整的句子回答
- 最后互相说“再见”

**参考表达**: 你好！ / 你叫什么名字？ / 我是……人。 / 很高兴认识你！ / 再见！

**表演时间**: 3-5分钟

---

## 2. 《买水果》（日常生活>购物）

**情景**: 你在水果店买水果

**角色A**: 你：顾客

**角色B**: 店员

**任务目标**: 买到你想买的水果：问价格、买几个、付钱

**语言要求**:
- 问“多少钱”
- 用“我要……”说想买的
- 说“谢谢”

**参考表达**: 你好！ / 这个多少钱？ / 我要两个。 / 一共多少钱？ / 谢谢！

**表演时间**: 3-5分钟

---

## 3. 《在餐厅点餐》（日常生活>饮食）

**情景**: 你在餐厅吃饭

**角色A**: 你：客人

**角色B**: 服务员

**任务目标**: 点好你的饭和饮料

**语言要求**:
- 说你想吃什么
- 说你想喝什么
- 说“谢谢”

**参考表达**: 我想吃…… / 我喝…… / 好的。 / 请等一下。 / 谢谢！

**表演时间**: 3-5分钟

---

## 4. 《问时间》（教育情况>校园生活）

**情景**: 你在学校，不知道现在几点

**角色A**: 你：学生

**角色B**: 另一个学生

**任务目标**: 问出现在几点，知道上课时间

**语言要求**:
- 问“现在几点了”
- 问上课时间
- 说“谢谢”

**参考表达**: 现在几点了？ / 现在……点了。 / 我们几点上课？ / 谢谢！

**表演时间**: 3分钟

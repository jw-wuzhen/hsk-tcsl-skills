# HSK4 角色扮演任务卡（4个）

本文件为角色扮演任务卡的参考样例。每张卡：情景 + 角色A/B + 任务目标 + 语言要求 + 参考表达 + 表演时间。生成新任务时按该等级语言边界设定“语言要求”与“参考表达”。

## 1. 《去银行办卡》（职场生活>日常办公）

**情景**: 你去银行办银行卡

**角色A**: 你：顾客

**角色B**: 银行职员

**任务目标**: 办成银行卡，知道取卡时间

**语言要求**:
- 说明要办什么
- 配合填写和签字
- 问清流程和时间

**参考表达**: 我想办一张银行卡。 / 请填一下这张表。 / 请在这里签字。 / 三个工作日后来取。

**表演时间**: 6-8分钟

---

## 2. 《公司面试》（职场生活>职业与经历）

**情景**: 你去一家公司面试

**角色A**: 你：应聘者

**角色B**: 面试官

**任务目标**: 介绍自己，说明你为什么适合这份工作

**语言要求**:
- 介绍自己的专业和经历
- 说明选择这家公司的原因
- 说出期望的工资

**参考表达**: 请介绍一下你自己。 / 我学的是…… / 因为……正好合适。 / 我希望月薪……左右。

**表演时间**: 8-10分钟

---

## 3. 《打电话报修》（日常生活>日常事务）

**情景**: 你家的空调坏了，给房东打电话

**角色A**: 你：租客

**角色B**: 房东

**任务目标**: 让房东尽快找人修好空调

**语言要求**:
- 说清问题
- 说明情况紧急
- 表示感谢

**参考表达**: 我房间的空调坏了。 / 晚上太热了，睡不着。 / 您能找人修吗？ / 太感谢您了！

**表演时间**: 5-8分钟

---

## 4. 《同事讨论加班》（职场生活>日常办公）

**情景**: 你和同事聊最近的工作

**角色A**: 你

**角色B**: 你的同事

**任务目标**: 互相分享压力，给对方建议

**语言要求**:
- 说自己的工作状态
- 表达压力
- 给对方一条建议

**参考表达**: 最近工作怎么样？ / 压力太大了。 / 要注意身体。 / 先做最重要的事。 / 周末放松一下。

**表演时间**: 6-8分钟

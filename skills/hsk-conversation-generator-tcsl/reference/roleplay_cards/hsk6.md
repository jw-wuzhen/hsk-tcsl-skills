# HSK6 角色扮演任务卡（4个）

本文件为角色扮演任务卡的参考样例。每张卡：情景 + 角色A/B + 任务目标 + 语言要求 + 参考表达 + 表演时间。生成新任务时按该等级语言边界设定“语言要求”与“参考表达”。

## 1. 《公司讨论人工智能》（科学技术>科技发展）

**情景**: 公司开会，讨论人工智能对工作的影响

**角色A**: 你：支持者（AI帮助工作）

**角色B**: 同事：担心者（AI抢工作）

**任务目标**: 双方各说3个理由，最后达成共识

**语言要求**:
- 用“在……的同时”
- 用“不仅……而且……”
- 提出一个共同行动方案

**参考表达**: 我认为…… / 但另一方面…… / 在……的同时…… / 我们需要……

**表演时间**: 10-12分钟

---

## 2. 《电视节目：人口老龄化》（当代社会>社会现象）

**情景**: 你是嘉宾，参加一个关于人口老龄化的电视节目

**角色A**: 你：专家嘉宾

**角色B**: 主持人

**任务目标**: 分析老龄化带来的挑战，提出三条对策

**语言要求**:
- 分析问题原因
- 提出具体对策
- 回答主持人追问

**参考表达**: 这是社会发展中一定会出现的情况。 / 正在完善…… / 长远来看…… / 需要全社会……

**表演时间**: 10-12分钟

---

## 3. 《新同事的文化困惑》（当代社会>中外交流）

**情景**: 外国新同事请你解释中国人说话的方式

**角色A**: 你：中国同事

**角色B**: 外国新同事

**任务目标**: 解释2-3个文化现象，帮同事适应

**语言要求**:
- 用“比如”举例
- 解释背后的原因
- 给同事一条适应建议

**参考表达**: 比如…… / 这是为了避免…… / 明白了。 / 学会这些，就能更好地交流。

**表演时间**: 8-10分钟

---

## 4. 《科技公司的隐私政策》（科学技术>科技发展）

**情景**: 一家科技公司讨论新产品收集数据的问题

**角色A**: 你：产品经理（收集数据做产品）

**角色B**: 同事：法务（保护用户隐私）

**任务目标**: 平衡商业利益和用户隐私，达成方案

**语言要求**:
- 双方说明立场
- 用“在……的同时”提出平衡方案
- 达成一致

**参考表达**: 我们需要在……之间找到平衡。 / 但完全拒绝也不现实。 / 可以在……的同时……

**表演时间**: 10-12分钟

# HSK2 角色扮演任务卡（4个）

本文件为角色扮演任务卡的参考样例。每张卡：情景 + 角色A/B + 任务目标 + 语言要求 + 参考表达 + 表演时间。生成新任务时按该等级语言边界设定“语言要求”与“参考表达”。

## 1. 《问路去车站》（日常生活>交通出行）

**情景**: 你在一个陌生的城市，想去火车站

**角色A**: 你：问路的人

**角色B**: 路人

**任务目标**: 问到去火车站的路，听明白怎么走

**语言要求**:
- 用“请问……”开始
- 听懂方向词（一直/左/右）
- 最后说“谢谢”

**参考表达**: 请问，去……怎么走？ / 一直往前走。 / 向左转。 / 远不远？ / 不客气。

**表演时间**: 4-6分钟

---

## 2. 《电话约朋友》（日常生活>交往）

**情景**: 你给朋友打电话，约他周末去看电影

**角色A**: 你

**角色B**: 你的朋友

**任务目标**: 约好时间、地点和电影

**语言要求**:
- 用“喂”开始
- 问对方有没有时间
- 说好几点、在哪儿见

**参考表达**: 喂，是……吗？ / 周末你有时间吗？ / 我们去看电影吧！ / 几点见？ / ……门口见。

**表演时间**: 4-6分钟

---

## 3. 《去医院看病》（日常生活>医疗健康）

**情景**: 你感冒了，去医院看病

**角色A**: 你：病人

**角色B**: 医生

**任务目标**: 说清楚哪里不舒服，听医生的建议

**语言要求**:
- 说“我……了”
- 回答医生的问题
- 复述医生让你做什么

**参考表达**: 你怎么了？ / 我头疼，还发烧。 / 多喝水。 / 休息两天。 / 谢谢医生。

**表演时间**: 4-6分钟

---

## 4. 《超市购物》（日常生活>购物）

**情景**: 你和朋友在超市，商量买什么

**角色A**: 你

**角色B**: 你的朋友

**任务目标**: 商量好购物清单，一起买完东西

**语言要求**:
- 说家里缺什么
- 问“还要……吗？”
- 决定买哪些

**参考表达**: 家里没有……了。 / 还要买……吗？ / 买一些……吧。 / 我们现在就去吧。

**表演时间**: 4-6分钟

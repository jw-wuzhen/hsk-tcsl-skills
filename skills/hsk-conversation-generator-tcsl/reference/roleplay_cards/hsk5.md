# HSK5 角色扮演任务卡（4个）

本文件为角色扮演任务卡的参考样例。每张卡：情景 + 角色A/B + 任务目标 + 语言要求 + 参考表达 + 表演时间。生成新任务时按该等级语言边界设定“语言要求”与“参考表达”。

## 1. 《采访：网购还是实体店？》（当代社会>经济现象）

**情景**: 你是一名记者，在街头采访路人

**角色A**: 你：记者

**角色B**: 路人

**任务目标**: 了解路人网购和去实体店的习惯，总结观点

**语言要求**:
- 记者问3个问题
- 路人说明理由
- 记者最后总结

**参考表达**: 请问您平时……？ / 您认为……？ / 比如呢？ / 谢谢您接受采访。

**表演时间**: 8-10分钟

---

## 2. 《家长会讨论》（教育情况>教育问题）

**情景**: 两个家长在讨论孩子学才艺的事

**角色A**: 家长A：主张多学才艺

**角色B**: 家长B：主张尊重兴趣

**任务目标**: 双方说明自己的观点，尽量说服对方

**语言要求**:
- 每人至少说两个理由
- 用“我认为/我觉得”
- 尊重对方的观点

**参考表达**: 我认为…… / 不过…… / 兴趣才是最好的老师。 / 怕孩子输在起跑线上。

**表演时间**: 8-10分钟

---

## 3. 《健身伙伴》（日常生活>日常事务）

**情景**: 你想健身，向有经验的朋友请教

**角色A**: 你：健身新手

**角色B**: 你的朋友：健身达人

**任务目标**: 得到一份可行的健身计划

**语言要求**:
- 新手说明困难
- 达人给出具体建议
- 新手复述计划

**参考表达**: 我总坚持不下来。 / 可以从简单的开始。 / 比如每天走路二十分钟。 / 我明天就开始。

**表演时间**: 6-8分钟

---

## 4. 《介绍春节》（文化与传统>民俗传统）

**情景**: 你给外国朋友介绍春节

**角色A**: 你：中国朋友

**角色B**: 外国朋友

**任务目标**: 介绍3个春节习俗，回答朋友的问题

**语言要求**:
- 介绍吃、贴、发等习俗
- 说明习俗的意思
- 邀请朋友来过年

**参考表达**: 我们吃年夜饭。 / 贴春联。 / 传说…… / 欢迎你来我家过年！

**表演时间**: 8-10分钟

# HSK1 场景对话脚本（7篇）

本文件为场景对话的参考样例。生成新对话时：对话只用该等级词汇和语法（超纲词★标注+拼音+母语翻译）；台词简短自然，贴近真实交际；结尾附学后任务。

## 1. 《你好！我叫王明》

**话题**: 自我介绍｜**话题树位置**: 基本信息>个人信息

**场景**: 学校门口，新同学第一次见面

**人物**: 王明、李华

**交际功能**: 问候与自我介绍｜**重点**: 主谓句、是字句、……吗？

**对话**:
- 王明：你好！我叫王明。你叫什么名字？
- 李华：你好！我叫李华。
- 王明：你是哪国人？
- 李华：我是美国人。你呢？
- 王明：我是中国人。很高兴认识你！
- 李华：我也很高兴认识你！

**关键词**: 名字、哪国、认识、高兴

**学后任务**: 两个人一组，用中文互相介绍自己，然后向全班介绍你的同桌。

## 2. 《你多大？》

**话题**: 年龄与家庭｜**话题树位置**: 基本信息>个人信息

**场景**: 教室，老师和新学生说话

**人物**: 老师、学生

**交际功能**: 询问年龄、介绍家庭｜**重点**: 有字句、量词：口、个

**对话**:
- 老师：你好！你多大？
- 学生：老师好！我十岁。
- 老师：你家有几口人？
- 学生：我家有三口人，爸爸、妈妈和我。
- 老师：你妈妈做什么工作？
- 学生：她是老师，我也喜欢当老师。

**关键词**: 多大、几、口、工作

**学后任务**: 问问你的同桌：他家有几口人？他妈妈做什么工作？

## 3. 《买苹果》

**话题**: 买东西｜**话题树位置**: 日常生活>购物

**场景**: 水果店

**人物**: 顾客、店员

**交际功能**: 询问价格、购买物品｜**重点**: 多少钱、量词：块、斤、个

**对话**:
- 顾客：你好！这个苹果多少钱？
- 店员：三块钱一斤。
- 顾客：我要两个。
- 店员：好的。一共六块钱。
- 顾客：给你钱。
- 店员：谢谢！欢迎再来！

**关键词**: 苹果、多少钱、块钱、斤

**学后任务**: 两人一组表演：在水果店买香蕉。

## 4. 《在餐厅》

**话题**: 点餐｜**话题树位置**: 日常生活>饮食

**场景**: 餐厅

**人物**: 服务员、客人

**交际功能**: 点餐、表达需要｜**重点**: 要+名词、量词：碗、杯、个

**对话**:
- 服务员：你好！你想吃什么？
- 客人：我要一碗米饭和一个菜。
- 服务员：你喝什么？
- 客人：我喝水。
- 服务员：好的，请等一下。
- 客人：谢谢！

**关键词**: 米饭、菜、喝、水

**学后任务**: 表演：你在中国餐厅点餐，服务员问你吃什么、喝什么。

## 5. 《今天天气真好》

**话题**: 天气｜**话题树位置**: 基本信息>环境信息

**场景**: 早上，两个朋友在楼下见面

**人物**: 小王、小张

**交际功能**: 谈论天气、提出建议｜**重点**: 天气怎么样、太……了、……吧

**对话**:
- 小王：早上好！今天天气怎么样？
- 小张：今天天气很好，不冷也不热。
- 小王：我们出去玩吧！
- 小张：太好了！去哪儿？
- 小王：去公园，公园里有花。
- 小张：好，我们走！

**关键词**: 天气、冷、热、公园、花

**学后任务**: 用中文说说：今天你那里的天气怎么样？

## 6. 《现在几点了？》

**话题**: 时间｜**话题树位置**: 教育情况>校园生活

**场景**: 教室里

**人物**: 王明、李华

**交际功能**: 询问和说明时间｜**重点**: 几点、……了

**对话**:
- 王明：现在几点了？
- 李华：现在八点了。
- 王明：我们几点上课？
- 李华：八点半。
- 王明：好，还有三十分钟。
- 李华：我们先看书吧。

**关键词**: 几点、上课、分钟

**学后任务**: 用中文说说：你今天几点起床？几点上课？几点吃饭？

## 7. 《这个字怎么读？》

**话题**: 学习中文｜**话题树位置**: 教育情况>学习情况

**场景**: 中文课，学生问老师

**人物**: 学生、老师

**交际功能**: 提问、表达理解｜**重点**: 怎么+动词、了（完成态）

**对话**:
- 学生：老师，这个字怎么读？
- 老师：这个字读“学”。
- 学生：我懂了，谢谢老师。
- 老师：不客气。你写一遍。
- 学生：好。（写）老师，我写得对吗？
- 老师：对，写得很好！

**关键词**: 读、写、对、懂

**学后任务**: 拿出你的课本，问同桌三个字的读法。

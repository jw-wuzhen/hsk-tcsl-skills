# HSK4 场景对话脚本（7篇）

本文件为场景对话的参考样例。生成新对话时：对话只用该等级词汇和语法（超纲词★标注+拼音+母语翻译）；台词简短自然，贴近真实交际；结尾附学后任务。

## 1. 《网上购物》

**话题**: 网购｜**话题树位置**: 科学技术>科技发展

**场景**: 两个朋友聊天

**人物**: 小王、小张

**交际功能**: 交流经验、提出建议｜**重点**: ……了（可能/结果）、先……才……

**对话**:
- 小王：你最近在网上买东西了吗？
- 小张：买了，在网上买书比书店便宜很多。
- 小王：网上购物方便，但是我看不见东西，怕买错了。
- 小张：所以要看评价，评价好的才买。
- 小王：你说得对，下次我也先看评价。
- 小张：还要注意选正规的商店，东西质量才有保证。

**关键词**: 网上购物、便宜、方便、评价、质量

**学后任务**: 用中文说说：你在网上买过什么？你觉得网上购物好不好？

## 2. 《办银行卡》

**话题**: 办卡｜**话题树位置**: 职场生活>日常办公

**场景**: 银行

**人物**: 顾客、银行职员

**交际功能**: 办理业务、说明要求｜**重点**: 请问……、……后

**对话**:
- 顾客：你好，我想办一张银行卡。
- 银行职员：请问您带身份证了吗？
- 顾客：带了，给您。
- 银行职员：好的，请填一下这张表，然后在这里签字。
- 顾客：好。请问可以存钱了吗？
- 银行职员：可以了。您的卡三个工作日后可以来取。
- 顾客：好的，谢谢！

**关键词**: 银行卡、身份证、填、表、签字

**超纲词**: ★工作日★ (gōngzuòrì) = working day

**学后任务**: 表演：你去银行办卡，职员问你要身份证，让你填表和签字。

## 3. 《面试》

**话题**: 求职面试｜**话题树位置**: 职场生活>职业与经历

**场景**: 公司办公室

**人物**: 面试官、王明

**交际功能**: 自我介绍、说明期望｜**重点**: 因为……所以……、正好

**对话**:
- 面试官：请介绍一下你自己。
- 王明：我叫王明，大学毕业，学的是中文。
- 面试官：你为什么想在我们公司工作？
- 王明：因为贵公司很重视国际交流，我的专业正好合适。
- 面试官：你希望工资是多少？
- 王明：我希望月薪五千左右。
- 面试官：好的，我们会通知你结果。

**关键词**: 面试、毕业、专业、工资、月薪

**学后任务**: 表演：你去面试，介绍自己，说明你为什么想得到这份工作。

## 4. 《挂号》

**话题**: 看病挂号｜**话题树位置**: 日常生活>医疗健康

**场景**: 医院

**人物**: 病人、医院工作人员

**交际功能**: 说明病情、询问流程｜**重点**: ……得厉害、大概

**对话**:
- 病人：请问怎么挂号？
- 工作人员：您哪里不舒服？
- 病人：我头疼得厉害。
- 工作人员：请先到二楼挂号，然后去内科。
- 病人：要排队很长时间吗？
- 工作人员：现在是上午，人不太多，大概二十分钟。
- 病人：好的，谢谢您。

**关键词**: 挂号、头疼、排队、内科

**超纲词**: ★内科★ (nèikē) = internal medicine (department)

**学后任务**: 表演：你肚子疼，去医院挂号看病。

## 5. 《空调坏了》

**话题**: 报修｜**话题树位置**: 日常生活>日常事务

**场景**: 电话里，租客联系房东

**人物**: 租客、房东

**交际功能**: 反映问题、商量解决办法｜**重点**: ……得+程度、让

**对话**:
- 租客：房东先生，我房间的空调坏了。
- 房东：天气这么热，没有空调可不行。
- 租客：您明天能找人修吗？
- 房东：我明天下午让师傅去看看。
- 租客：可以今天晚上来吗？晚上太热了，睡不着。
- 房东：好吧，我现在就给师傅打电话。
- 租客：太感谢您了！

**关键词**: 空调、坏、修、师傅、感谢

**学后任务**: 表演：你的冰箱坏了，给房东打电话，请他尽快找人修。

## 6. 《工作压力》

**话题**: 加班｜**话题树位置**: 职场生活>日常办公

**场景**: 公司，两个同事聊天

**人物**: 小张、小李

**交际功能**: 表达感受、提出建议｜**重点**: ……得+程度、先……再……

**对话**:
- 小张：最近工作怎么样？
- 小李：太忙了，每天加班到九点。
- 小张：你压力太大了，要注意身体。
- 小李：我也知道，但是工作做不完，没办法。
- 小张：你试着安排一下时间，先做最重要的事。
- 小李：你说得对，我试试看。
- 小张：周末也要休息休息，放松一下。

**关键词**: 加班、压力、身体、安排、放松

**学后任务**: 用中文说说：你觉得工作忙的时候应该怎么办？

## 7. 《坐地铁上班》

**话题**: 通勤方式｜**话题树位置**: 日常生活>交通出行

**场景**: 两个同事在办公室

**人物**: 小张、小李

**交际功能**: 比较交通方式｜**重点**: ……是……，但是……、顺便

**对话**:
- 小张：你每天怎么上班？
- 小李：我坐地铁，快是快，但是早上人太多。
- 小张：我骑车上班，路上还能锻炼身体。
- 小李：骑车安全吗？
- 小张：我骑得很慢，走小路，很安全。
- 小李：那我也试试，顺便减肥。

**关键词**: 地铁、上班、骑车、锻炼、安全

**学后任务**: 比较一下：坐地铁和骑车上班，各有什么好处和坏处？

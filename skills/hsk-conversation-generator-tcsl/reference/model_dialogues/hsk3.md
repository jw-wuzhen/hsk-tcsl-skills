# HSK3 场景对话脚本（7篇）

本文件为场景对话的参考样例。生成新对话时：对话只用该等级词汇和语法（超纲词★标注+拼音+母语翻译）；台词简短自然，贴近真实交际；结尾附学后任务。

## 1. 《暑假去哪儿旅行？》

**话题**: 旅行计划｜**话题树位置**: 日常生活>交通出行

**场景**: 两个朋友商量暑假旅行

**人物**: 小王、小张

**交际功能**: 商量计划、比较选择｜**重点**: 虽然……但是……、……一些

**对话**:
- 小王：暑假你想去哪儿旅行？
- 小张：我想去北京。北京好玩儿的地方很多。
- 小王：坐火车去还是坐飞机去？
- 小张：坐飞机快一些，但是贵。
- 小王：坐火车虽然慢，但是可以看风景。
- 小张：那就坐火车吧，还可以省一些钱。
- 小王：好，我们回去好好准备。

**关键词**: 旅行、好玩儿、火车、飞机、风景

**学后任务**: 用“虽然……但是……”说说：坐火车和坐飞机，你选哪个？为什么？

## 2. 《看房子》

**话题**: 租房｜**话题树位置**: 日常生活>日常事务

**场景**: 房东带人看房子

**人物**: 看房人、房东

**交际功能**: 说明条件、询问价格｜**重点**: ……了（可能）、把……

**对话**:
- 看房人：你好，我来看房子。
- 房东：请进来。这套房子怎么样？
- 看房人：房子不错，但是有点小。
- 房东：两个人住够了。
- 看房人：一个月多少钱？
- 房东：两千五，包括水电费。
- 看房人：可以，我明天搬进来。
- 房东：好，我们先把合同签了。

**关键词**: 房子、住、钱、水电费、合同

**学后任务**: 表演：你要租房子，问房东房子的大小、价钱和水电费。

## 3. 《我想换一件小的》

**话题**: 退换商品｜**话题树位置**: 日常生活>购物

**场景**: 商店，顾客来换衣服

**人物**: 顾客、店员

**交际功能**: 说明问题、提出要求｜**重点**: 把字句、可能补语：得

**对话**:
- 顾客：你好，我前天在这里买了一件衣服，太大，想换一件小的。
- 店员：请把衣服和收据给我看看。
- 顾客：好的，给你。
- 店员：可以换。请问你要什么颜色的？
- 顾客：换那件蓝色的。
- 店员：好的，请你试一下，看看合适不合适。
- 顾客：这件刚好，我就要这件。

**关键词**: 换、收据、颜色、试、合适

**学后任务**: 表演：你买了一件衣服，大小不合适，去商店换一件。

## 4. 《老师，我想请假》

**话题**: 请假｜**话题树位置**: 教育情况>校园生活

**场景**: 办公室，学生向老师请假

**人物**: 学生、老师

**交际功能**: 请假、说明原因｜**重点**: 想+动词、让

**对话**:
- 学生：老师，我明天想请假。
- 老师：你怎么了？
- 学生：我感冒了，医生让我休息。
- 老师：好，你在家好好休息。
- 学生：那作业怎么办？
- 老师：作业后天交，不要担心。
- 学生：谢谢老师。

**关键词**: 请假、休息、作业、担心

**学后任务**: 表演：你发烧了，向老师请一天假。

## 5. 《来我家吃饭》

**话题**: 请客｜**话题树位置**: 日常生活>饮食

**场景**: 朋友来家里吃饭

**人物**: 小张、小王

**交际功能**: 请客、夸赞｜**重点**: 别客气、是……的

**对话**:
- 小张：来，多吃点，别客气。
- 小王：谢谢！这个菜真好吃，是你做的吗？
- 小张：是我做的，我还做了汤。
- 小王：你手艺真好，以后教教我吧。
- 小张：当然可以。你先喝汤，尝尝好不好喝。
- 小王：好喝极了！下次我也要做给你吃。

**关键词**: 客气、好吃、汤、手艺、教

**超纲词**: ★手艺★ (shǒuyì) = skill (in cooking/craft)

**学后任务**: 用“是……的”说三句话：你的书包、衣服、中文是在哪里买的/学的？

## 6. 《这部电影怎么样？》

**话题**: 看电影｜**话题树位置**: 当代社会>文艺

**场景**: 看完电影后

**人物**: 小王、小张

**交际功能**: 表达看法｜**重点**: 觉得、虽然……但是……

**对话**:
- 小王：你觉得这部电影怎么样？
- 小张：我觉得很好看，但是有点长。
- 小王：我最喜欢最后的部分，很感动。
- 小张：我也觉得，那个演员演得真好。
- 小王：下次我们再看一部吧。
- 小张：好，下次选一部短一点的。

**关键词**: 电影、觉得、感动、演员、演

**学后任务**: 说说：你最近看的一部电影怎么样？用“我觉得……”。

## 7. 《保护环境》

**话题**: 环保｜**话题树位置**: 自然与环境>环境

**场景**: 学校环保活动后

**人物**: 老师、学生

**交际功能**: 说明做法、提出建议｜**重点**: 把字句、为了

**对话**:
- 老师：今天我们学了环保。你平时怎么做？
- 学生：我出门都带自己的袋子，不用塑料袋。
- 老师：很好！还有吗？
- 学生：我把旧书送给别人，不随便扔。
- 老师：对，把还可以用的东西留下来，就是保护环境。
- 学生：老师，我们还能做什么？
- 老师：少开车，多走路，空气会更干净。

**关键词**: 环境、袋子、旧、扔、空气

**超纲词**: ★塑料袋★ (sùliàodài) = plastic bag

**学后任务**: 用“把”说三句话：你平时怎么保护环境？

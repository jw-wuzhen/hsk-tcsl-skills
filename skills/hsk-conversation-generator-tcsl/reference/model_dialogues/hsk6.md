# HSK6 场景对话脚本（6篇）

本文件为场景对话的参考样例。生成新对话时：对话只用该等级词汇和语法（超纲词★标注+拼音+母语翻译）；台词简短自然，贴近真实交际；结尾附学后任务。

## 1. 《人工智能会取代人类吗？》

**话题**: 人工智能｜**话题树位置**: 科学技术>科技发展

**场景**: 一次讨论会

**人物**: 主持人、嘉宾A、嘉宾B

**交际功能**: 深入讨论、论证观点｜**重点**: 在……的同时、不仅……而且……

**对话**:
- 主持人：有人说人工智能会取代很多工作，你们怎么看？
- 嘉宾A：我认为它会改变就业结构，但不会完全取代人类。
- 主持人：为什么这么说？
- 嘉宾A：重复性的工作容易被替代，但需要创造力的工作很难。
- 嘉宾B：我同意，而且人工智能还能帮人类做很多危险的工作。
- 主持人：那我们普通人该怎么办？
- 嘉宾B：终身学习，不断更新自己的技能，跟上时代。

**关键词**: 人工智能、取代、就业、技能、时代

**超纲词**: ★重复性★ (chóngfùxìng) = repetitive (in nature)；★终身学习★ (zhōngshēn xuéxí) = lifelong learning

**学后任务**: 讨论：人工智能时代，你打算学习什么新技能？为什么？

## 2. 《买房还是租房？》

**话题**: 房价问题｜**话题树位置**: 当代社会>经济现象

**场景**: 两个朋友讨论社会热点

**人物**: 小张、小王

**交际功能**: 分析社会现象｜**重点**: 一方面……另一方面……、在……下

**对话**:
- 小张：这几年房价涨得很快，年轻人买房越来越难。
- 小王：是啊，大城市房价太高，很多人选择租房。
- 小张：政府出台了很多政策，但短期内效果有限。
- 小王：一方面人们的需求还在增长，另一方面土地资源有限。
- 小张：长远来看，市场会慢慢稳定下来。
- 小王：希望那时候我们都能买得起房子。

**关键词**: 房价、政策、需求、稳定、资源

**超纲词**: ★出台★ (chūtái) = to introduce (policies)

**学后任务**: 讨论：买房和租房，你更赞成哪个？说明理由。

## 3. 《中国历史》

**话题**: 历史话题｜**话题树位置**: 文化与传统>历史

**场景**: 外国留学生和中国朋友聊天

**人物**: 汤姆、王明

**交际功能**: 介绍历史文化｜**重点**: 之一、当时

**对话**:
- 汤姆：你了解中国的历史吗？
- 王明：了解一些。中国有五千年的历史，很有意思。
- 汤姆：比如呢？
- 王明：比如唐朝，那是中国历史上最繁荣的时期之一。
- 汤姆：我听说长安当时是世界上最大的城市。
- 王明：对，那时有很多外国人来中国学习。

**关键词**: 历史、繁荣、时期、当时、学习

**超纲词**: ★繁荣★ (fánróng) = prosperous, booming

**学后任务**: 用中文介绍一个你感兴趣的历史时期或历史人物。

## 4. 《人口老龄化》

**话题**: 社会老龄化｜**话题树位置**: 当代社会>社会现象

**场景**: 电视节目讨论

**人物**: 主持人、专家

**交际功能**: 分析社会问题、提出对策｜**重点**: 在……的同时、面临……挑战

**对话**:
- 主持人：中国现在人口老龄化越来越严重，您怎么看？
- 专家：这是社会发展中一定会出现的情况，但也带来了养老的挑战。
- 主持人：政府采取了哪些措施？
- 专家：正在完善养老制度，鼓励生育，发展银发经济。
- 主持人：我们个人可以做些什么？
- 专家：提前做好养老规划，多锻炼身体，保持健康。

**关键词**: 老龄化、养老、制度、健康、规划

**超纲词**: ★老龄化★ (lǎolínghuà) = aging of the population；★银发经济★ (yínfà jīngjì) = silver economy (products/services for the elderly)

**学后任务**: 讨论：你身边有老年人吗？你觉得社会应该怎样关心老年人？

## 5. 《文化差异》

**话题**: 跨文化交际｜**话题树位置**: 当代社会>中外交流

**场景**: 外国同事和中国同事聊天

**人物**: 约翰、李华

**交际功能**: 讨论文化差异｜**重点**: 避免、因此

**对话**:
- 约翰：在中国工作，我经常遇到文化差异带来的困惑。
- 李华：比如呢？
- 约翰：比如中国人说话比较委婉，有时候不说“不”，而是说“再看看”。
- 李华：明白了，这是为了避免让对方难堪。
- 约翰：现在我慢慢学会了，听懂字面以外的意思很重要。
- 李华：你适应得真快！学会这些，就能更好地交流。

**关键词**: 文化差异、委婉、难堪、适应、交流

**超纲词**: ★委婉★ (wěiwǎn) = tactful, euphemistic；★难堪★ (nánkān) = embarrassed, awkward；★字面★ (zìmiàn) = literal meaning (of words)

**学后任务**: 讨论：你有没有遇到过文化差异？说说你的经历。

## 6. 《大数据时代的隐私》

**话题**: 科技与隐私｜**话题树位置**: 科学技术>科技发展

**场景**: 两个朋友讨论

**人物**: 小张、小王

**交际功能**: 深入讨论、表达担忧｜**重点**: 在……的同时、平衡

**对话**:
- 小张：你觉得大数据时代还有隐私吗？
- 小王：隐私越来越难保护，我们的数据无处不在。
- 小张：你会担心吗？
- 小王：会，所以我很少在网络上分享个人信息。
- 小张：但完全拒绝科技也不现实。
- 小王：是的，我们需要在便利和隐私之间找到平衡。

**关键词**: 大数据、隐私、数据、分享、平衡

**超纲词**: ★隐私★ (yǐnsī) = privacy；★无处不在★ (wúchùbùzài) = ubiquitous, everywhere

**学后任务**: 讨论：为了保护隐私，你平时会注意什么？

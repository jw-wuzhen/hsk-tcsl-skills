# HSK5 场景对话脚本（6篇）

本文件为场景对话的参考样例。生成新对话时：对话只用该等级词汇和语法（生词★标注+拼音+母语翻译）；台词简短自然，贴近真实交际；结尾附学后任务。

## 1. 《网上购物会取代实体店吗？》

**话题**: 网购与实体店｜**话题树位置**: 当代社会>经济现象

**场景**: 两个朋友讨论

**人物**: 小张、小王

**交际功能**: 发表观点、论证｜**重点**: 虽然……但是……、比如

**对话**:
- 小张：你觉得网上购物会取代实体店吗？
- 小王：我觉得不会。网上购物虽然方便，但实体店有自己的优势。
- 小张：比如呢？
- 小王：比如可以试衣服、亲眼看到商品，服务也更直接。
- 小张：不过网上选择更多、价格更便宜。
- 小王：所以我认为两者会长期一起存在，谁也代替不了谁。
- 小张：有道理。我以后买衣服还是去实体店。

**关键词**: 取代、实体店、优势、选择、价格

**生词**: ★亲眼★ (qīnyǎn) = with one's own eyes

**学后任务**: 小组讨论：你买东西更喜欢网购还是去实体店？说明理由。

## 2. 《孩子该学多少才艺？》

**话题**: 才艺教育｜**话题树位置**: 教育情况>教育问题

**场景**: 两个家长聊天

**人物**: 家长A、家长B

**交际功能**: 表达观点、反驳｜**重点**: 认为、不过

**对话**:
- 家长A：现在很多孩子学好多才艺，你觉得有必要吗？
- 家长B：我认为没必要都学，应该尊重孩子的兴趣。
- 家长A：可很多家长怕孩子输在起跑线上。
- 家长B：但快乐成长更重要，兴趣才是最好的老师。
- 家长A：话是这么说，可别人都学，自己孩子不学行吗？
- 家长B：可以让孩子选一两样最喜欢的，坚持学下去。

**关键词**: 才艺、尊重、兴趣、坚持、成长

**生词**: ★起跑线★ (qǐpǎoxiàn) = starting line (of a race), metaphor for life's starting point

**学后任务**: 辩论：你觉得孩子小时候应该多学才艺吗？说出两个理由。

## 3. 《健身计划》

**话题**: 健康生活｜**话题树位置**: 日常生活>日常事务

**场景**: 两个朋友聊天

**人物**: 小张、小王

**交际功能**: 交流经验、鼓励｜**重点**: 坚持、从……开始

**对话**:
- 小张：你最近在健身吗？
- 小王：是啊，我每天跑步半小时，已经坚持三个月了。
- 小张：效果怎么样？
- 小王：明显感觉有精神了，睡眠也好了。
- 小张：我也想运动，但总是坚持不下来。
- 小王：可以从简单的开始，比如每天走路二十分钟。
- 小张：好，我明天就开始。

**关键词**: 健身、坚持、效果、精神、睡眠

**学后任务**: 用中文说说：你有什么健康的生活习惯？你是怎么坚持的？

## 4. 《垃圾分类》

**话题**: 环保措施｜**话题树位置**: 自然与环境>环境

**场景**: 两个同事讨论

**人物**: 小张、小李

**交际功能**: 发表看法、说明利弊｜**重点**: 有利于、需要……才……

**对话**:
- 小张：我们城市最近在推行垃圾分类，你觉得怎么样？
- 小李：我支持，垃圾分类有利于保护环境。
- 小张：但是执行起来很麻烦，很多人分不清楚。
- 小李：所以需要宣传和教育，时间长了就习惯了。
- 小张：希望大家都配合，环境才会越来越好。
- 小李：对，保护环境人人有责。

**关键词**: 垃圾、分类、支持、宣传、配合

**生词**: ★人人有责★ (rénrén yǒu zé) = everyone is responsible

**学后任务**: 小组讨论：你支持垃圾分类吗？说说你的看法。

## 5. 《小张升职了》

**话题**: 职场晋升｜**话题树位置**: 职场生活>经营与管理

**场景**: 公司里，两个同事聊天

**人物**: 小李、小王

**交际功能**: 评论、总结｜**重点**: 除了……还……、认为

**对话**:
- 小李：听说小张升职了？
- 小王：是的，他工作认真，能力也强。
- 小李：你觉得升职最重要的是什么？
- 小王：我认为除了能力，责任心和沟通能力也很重要。
- 小李：说得对。我也要多向他学习。
- 小王：我们好好工作，以后也有机会。

**关键词**: 升职、能力、责任心、沟通、机会

**学后任务**: 小组讨论：你觉得一个员工升职需要哪些条件？

## 6. 《介绍春节》

**话题**: 中国节日｜**话题树位置**: 文化与传统>民俗传统

**场景**: 中国朋友给外国朋友介绍春节

**人物**: 王明、汤姆

**交际功能**: 介绍文化习俗｜**重点**: 除了……还……、……的时候

**对话**:
- 汤姆：你们过春节有什么习俗？
- 王明：我们吃年夜饭、贴春联、放鞭炮、给小孩红包。
- 汤姆：为什么要放鞭炮？
- 王明：传说可以赶走不好的东西，带来好运。
- 汤姆：真有意思！我也想体验一下。
- 王明：欢迎你今年来我家过年！

**关键词**: 春节、习俗、红包、好运、过年

**生词**: ★春联★ (chūnlián) = Spring Festival couplets；★鞭炮★ (biānpào) = firecrackers

**学后任务**: 用中文介绍一个你们国家的重要节日，说说人们做什么。

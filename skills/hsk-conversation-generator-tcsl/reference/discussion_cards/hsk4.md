# HSK4 话题问题卡（4组）

本文件为话题问题卡的参考样例。分级原则：HSK1 是非问答 → HSK3 “如果…就”条件句 → HSK6 抽象议题辩论。每张卡分 warmup（热身）/ core（核心）/ extended（拓展），并带教师提示（答题框架）。

## 1. 话题：网上购物（科学技术>科技发展）

- **warmup** 你经常在网上买东西吗？（教师提示：用“经常/有时候/很少”）
- **warmup** 你最近买了什么？（教师提示：复习“最近”和“了”）
- **core** 网上购物有什么好处？（教师提示：用“方便/便宜/选择多”）
- **core** 网上购物有什么问题？（教师提示：用“看不见/质量/退货”）
- **core** 你买东西前先做什么？（教师提示：用“先看评价/先比价格”）
- **extended** 你觉得实体店会消失吗？为什么？（教师提示：说出你的看法和两个理由）

---

## 2. 话题：工作与压力（职场生活>日常办公）

- **warmup** 你工作忙吗？（教师提示：用“很忙/不太忙”）
- **warmup** 你每天几点下班？（教师提示：用时间表达）
- **core** 你觉得工作压力大吗？（教师提示：用“压力很大/有一点”）
- **core** 压力大的时候你怎么办？（教师提示：用“运动/听音乐/休息”）
- **core** 工作和身体，哪个重要？（教师提示：说出你的看法）
- **extended** 你觉得加班好不好？为什么？（教师提示：正反两方面说）

---

## 3. 话题：出行方式（日常生活>交通出行）

- **warmup** 你每天怎么上班（上学）？（教师提示：用“坐地铁/坐车/骑车/走路”）
- **warmup** 路上要多长时间？（教师提示：用“大概……分钟”）
- **core** 坐地铁有什么好处？（教师提示：用“快/不堵车/方便”）
- **core** 骑车有什么好处？（教师提示：用“锻炼身体/省钱/环保”）
- **core** 你最喜欢哪种出行方式？（教师提示：说出理由）
- **extended** 你觉得你们城市的交通怎么样？（教师提示：用“很方便/很堵/需要改进”）

---

## 4. 话题：看病（日常生活>医疗健康）

- **warmup** 你经常生病吗？（教师提示：用“很少/有时候”）
- **warmup** 你上次生病是什么时候？（教师提示：复习时间表达）
- **core** 你生病的时候做什么？（教师提示：用“吃药/休息/去医院”）
- **core** 你觉得怎么预防感冒？（教师提示：用“多喝水/多运动/早睡觉”）
- **core** 你相信中药还是西药？（教师提示：说出你的看法和原因）
- **extended** 如果医生让你住院，你会怎么办？（教师提示：假设性问答）

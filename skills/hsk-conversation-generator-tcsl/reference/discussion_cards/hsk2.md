# HSK2 话题问题卡（4组）

本文件为话题问题卡的参考样例。分级原则：HSK1 是非问答 → HSK3 “如果…就”条件句 → HSK6 抽象议题辩论。每张卡分 warmup（热身）/ core（核心）/ extended（拓展），并带教师提示（答题框架）。

## 1. 话题：问路（日常生活>交通出行）

- **warmup** 你去过中国吗？（教师提示：复习“去过”）
- **warmup** 你去哪儿？（教师提示：用“我去……”）
- **core** 去火车站怎么走？（教师提示：用“一直走/向左转/向右转”）
- **core** 远不远？（教师提示：用“很远/不远/走路十分钟”）
- **core** 你坐什么车去学校？（教师提示：用“坐……车/走路”）
- **extended** 为什么你坐车不走路？（教师提示：用“因为……所以……”）

---

## 2. 话题：周末活动（日常生活>交往）

- **warmup** 你周末做什么？（教师提示：用“我……/我打算……”）
- **warmup** 你喜欢周末吗？（教师提示：用“喜欢/不喜欢”+原因）
- **core** 你打算去哪儿？（教师提示：用“我打算去……”）
- **core** 和谁一起去？（教师提示：用“我和……一起去”）
- **core** 几点去？（教师提示：用“我们……点去”）
- **extended** 为什么你想去那里？（教师提示：用“因为……”）

---

## 3. 话题：看病（日常生活>医疗健康）

- **warmup** 你身体好吗？（教师提示：用“很好/不太好”）
- **warmup** 你怎么了？（教师提示：用“我头疼/我感冒了”）
- **core** 你哪里不舒服？（教师提示：说出身体部位）
- **core** 你昨天做什么了？（教师提示：复习“了”）
- **core** 医生让你做什么？（教师提示：用“医生让我……”）
- **extended** 你觉得怎么才能不生病？（教师提示：用“要多……/要少……”）

---

## 4. 话题：餐厅点菜（日常生活>饮食）

- **warmup** 你爱吃什么？（教师提示：用“我爱吃……”）
- **warmup** 你妈妈会做饭吗？（教师提示：用“会/不会”）
- **core** 你点菜的时候说什么？（教师提示：用“我要……/再来一个……”）
- **core** 你最喜欢哪个菜？（教师提示：用“我最喜欢……”）
- **core** 你们几个人吃饭？（教师提示：用数量词）
- **extended** 你觉得中国菜怎么样？（教师提示：用“很好吃/有一点咸/太辣了”）

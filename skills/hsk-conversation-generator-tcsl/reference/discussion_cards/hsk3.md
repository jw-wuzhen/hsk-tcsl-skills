# HSK3 话题问题卡（4组）

本文件为话题问题卡的参考样例。分级原则：HSK1 是非问答 → HSK3 “如果…就”条件句 → HSK6 抽象议题辩论。每张卡分 warmup（热身）/ core（核心）/ extended（拓展），并带教师提示（答题框架）。

## 1. 话题：旅行计划（日常生活>交通出行）

- **warmup** 你喜欢旅行吗？（教师提示：用“喜欢/不喜欢”+原因）
- **warmup** 你去过哪些地方？（教师提示：复习“去过/没去过”）
- **core** 你打算怎么去？（教师提示：用“坐火车/坐飞机/开车”）
- **core** 如果钱不够怎么办？（教师提示：用“如果……就……”）
- **core** 旅行的时候你带什么？（教师提示：用“我带了……”）
- **extended** 你觉得旅行有什么好处？（教师提示：用“可以……”说两点）

---

## 2. 话题：买东西（日常生活>购物）

- **warmup** 你喜欢买东西吗？（教师提示：用“喜欢/不喜欢”+原因）
- **warmup** 你买过最贵的东西是什么？（教师提示：复习“过”）
- **core** 你觉得网上买东西怎么样？（教师提示：用“很方便/便宜/看不见东西”）
- **core** 如果买的东西不合适怎么办？（教师提示：用“换/退/告诉店员”）
- **core** 你买东西的时候看什么？（教师提示：用“看质量/看价格/看颜色”）
- **extended** 为什么大家喜欢买便宜的东西？（教师提示：用“因为……所以……”）

---

## 3. 话题：请客（日常生活>饮食）

- **warmup** 你请过朋友吃饭吗？（教师提示：用“请过/没请过”）
- **warmup** 你会做什么菜？（教师提示：用“我会做……”）
- **core** 客人来了，你说什么？（教师提示：用“请进/请坐/别客气/多吃点”）
- **core** 你觉得主人的菜怎么样？（教师提示：用“真好吃/味道不错”）
- **core** 中国人请客的时候怎么做？（教师提示：用“让客人先吃/给客人夹菜”）
- **extended** 如果朋友做的菜不好吃，你说什么？（教师提示：学习礼貌表达）

---

## 4. 话题：保护环境（自然与环境>环境）

- **warmup** 你们国家的环境好吗？（教师提示：用“空气/水/树……”）
- **warmup** 你喜欢大自然吗？（教师提示：用“喜欢/不喜欢”+原因）
- **core** 你平时怎么保护环境？（教师提示：用“我把……/我少用……”）
- **core** 如果大家都扔垃圾会怎么样？（教师提示：用“如果……就……”）
- **core** 为什么要少开车？（教师提示：用“因为……所以……”）
- **extended** 你觉得地球以后会怎么样？（教师提示：自由表达，允许新词）

# HSK5 话题问题卡（4组）

本文件为话题问题卡的参考样例。分级原则：HSK1 是非问答 → HSK3 “如果…就”条件句 → HSK6 抽象议题辩论。每张卡分 warmup（热身）/ core（核心）/ extended（拓展），并带教师提示（答题框架）。

## 1. 话题：网购与实体店（当代社会>经济现象）

- **warmup** 你上一次购物是在网上还是实体店？（教师提示：回忆性叙述）
- **warmup** 你喜欢逛街吗？（教师提示：用“喜欢/不喜欢”+原因）
- **core** 网上购物有哪些优势？（教师提示：列举2-3点）
- **core** 实体店有哪些网上购物比不了的？（教师提示：用“比如……”）
- **core** 你认为网购会取代实体店吗？（教师提示：明确观点+论证）
- **extended** 如果你是实体店老板，你怎么吸引顾客？（教师提示：创造性回答）

## 2. 话题：教育问题（教育情况>教育问题）

- **warmup** 你觉得学习中文难吗？（教师提示：说出难点）
- **warmup** 你小时候喜欢上学吗？（教师提示：回忆性叙述）
- **core** 孩子应该多学才艺吗？（教师提示：明确观点+理由）
- **core** 你认为考试重要吗？（教师提示：正反两方面说）
- **core** 老师应该怎么鼓励学生？（教师提示：提出具体做法）
- **extended** 你怎么看待“不要输在起跑线上”这句话？（教师提示：深层讨论）

---

## 3. 话题：健康生活（日常生活>日常事务）

- **warmup** 你睡眠好吗？（教师提示：用“很好/不太好/失眠”）
- **warmup** 你每天运动多长时间？（教师提示：用“大概……分钟”）
- **core** 你觉得什么样的生活是健康的？（教师提示：列举2-3点）
- **core** 为什么很多人坚持不了运动？（教师提示：分析原因）
- **core** 快餐对身体有什么影响？（教师提示：用“高油/高盐/肥胖”）
- **extended** 如果你有一个月时间改变生活习惯，你打算怎么做？（教师提示：制定计划）

---

## 4. 话题：传统节日（文化与传统>民俗传统）

- **warmup** 你最喜欢什么节日？（教师提示：用“我最喜欢……”）
- **warmup** 你们国家过什么节日？（教师提示：列举2-3个）
- **core** 中国春节有什么习俗？（教师提示：用“贴春联/吃年夜饭/发红包”）
- **core** 为什么节日对人们重要？（教师提示：分析意义）
- **core** 年轻人为什么不太喜欢传统节日了？（教师提示：对比分析）
- **extended** 如果你在中国过年，你最想体验什么？（教师提示：文化体验表达）

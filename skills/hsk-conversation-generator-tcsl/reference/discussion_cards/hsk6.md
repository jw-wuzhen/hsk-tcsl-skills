# HSK6 话题问题卡（4组）

本文件为话题问题卡的参考样例。分级原则：HSK1 是非问答 → HSK3 “如果…就”条件句 → HSK6 抽象议题辩论。每张卡分 warmup（热身）/ core（核心）/ extended（拓展），并带教师提示（答题框架）。

## 1. 话题：人工智能（科学技术>科技发展）

- **warmup** 你生活中用过人工智能吗？（教师提示：举例：翻译软件、导航）
- **warmup** 你觉得人工智能聪明吗？（教师提示：比较人与机器）
- **core** 人工智能会给就业带来什么影响？（教师提示：分析正反两面）
- **core** 哪些工作最容易被取代？（教师提示：分类分析）
- **core** 人应该怎样和人工智能相处？（教师提示：提出原则）
- **extended** 人工智能会不会有自我意识？你怎么看？（教师提示：开放讨论，鼓励深度表达）

---

## 2. 话题：人口老龄化（当代社会>社会现象）

- **warmup** 你身边有老年人吗？（教师提示：家庭情况分享）
- **warmup** 你和老年人一起生活过吗？（教师提示：回忆性叙述）
- **core** 人口老龄化会带来哪些问题？（教师提示：养老/劳动力/医疗）
- **core** 社会可以怎样帮助老年人？（教师提示：政府+社会+家庭）
- **core** 年轻人愿意和父母一起住吗？（教师提示：分析两种选择）
- **extended** 如果你老了，你希望过什么样的生活？（教师提示：展望性表达）

---

## 3. 话题：跨文化交际（当代社会>中外交流）

- **warmup** 你和外国人打过交道吗？（教师提示：分享经历）
- **warmup** 学中文时最难的是什么？（教师提示：对比母语）
- **core** 文化差异会带来哪些误会？（教师提示：举例说明）
- **core** 遇到文化差异应该怎么办？（教师提示：尊重/理解/沟通）
- **core** 你们国家和中国有哪些不同的习惯？（教师提示：对比分析）
- **extended** 全球化让文化越来越一样，你觉得好吗？（教师提示：深层讨论）

---

## 4. 话题：隐私保护（科学技术>科技发展）

- **warmup** 你用手机上网多吗？（教师提示：分享使用习惯）
- **warmup** 你会在网上分享个人信息吗？（教师提示：说出现在做法）
- **core** 大数据知道你的哪些信息？（教师提示：举例：位置/爱好/消费）
- **core** 科技公司为什么想要你的数据？（教师提示：商业逻辑分析）
- **core** 怎么保护自己的隐私？（教师提示：提出具体方法）
- **extended** 便利和隐私，哪个更重要？（教师提示：辩论式讨论）

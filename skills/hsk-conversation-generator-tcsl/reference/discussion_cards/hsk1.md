# HSK1 话题问题卡（4组）

本文件为话题问题卡的参考样例。分级原则：HSK1 是非问答 → HSK3 “如果…就”条件句 → HSK6 抽象议题辩论。每张卡分 warmup（热身）/ core（核心）/ extended（拓展），并带教师提示（答题框架）。

## 1. 话题：自我介绍（基本信息>个人信息）

- **warmup** 你叫什么名字？（教师提示：完整回答：我叫……）
- **warmup** 你是哪国人？（教师提示：回答：我是……人）
- **core** 你家有几口人？（教师提示：用数量词：我家有三口人）
- **core** 你喜欢什么？（教师提示：用“我喜欢……”）
- **core** 你多大？（教师提示：用“我……岁”）
- **extended** 你的朋友叫什么名字？（教师提示：练习第三人称：他叫……）

---

## 2. 话题：买东西（日常生活>购物）

- **warmup** 这个多少钱？（教师提示：用“……块钱”回答）
- **warmup** 你要什么？（教师提示：用“我要……”）
- **core** 你想买什么？（教师提示：用“我想买……”）
- **core** 你买几个？（教师提示：数量词：两个、三斤）
- **core** 一共多少钱？（教师提示：练习加法：一共……块钱）
- **extended** 你买东西的时候说什么？（教师提示：复习：你好、谢谢、再见）

---

## 3. 话题：点餐（日常生活>饮食）

- **warmup** 你想吃什么？（教师提示：用“我想吃……”）
- **warmup** 你喝什么？（教师提示：用“我喝……”）
- **core** 你喜欢吃什么菜？（教师提示：用“我喜欢……”）
- **core** 你要几个？（教师提示：用数量词）
- **core** 你吃饭了吗？（教师提示：中国人常问的一句话）
- **extended** 你会做菜吗？（教师提示：用“会/不会”回答）

---

## 4. 话题：天气（基本信息>环境信息）

- **warmup** 今天天气怎么样？（教师提示：用“很好/不太好/很冷……”）
- **warmup** 今天冷不冷？（教师提示：用“很冷/不冷/有一点冷”）
- **core** 你喜欢什么天气？（教师提示：用“我喜欢……”）
- **core** 你喜欢下雨吗？（教师提示：是非问答+原因）
- **core** 今天有什么？（教师提示：用“有”字句：今天有风/有雨）
- **extended** 天气好的时候你做什么？（教师提示：用“我……”复习动作）

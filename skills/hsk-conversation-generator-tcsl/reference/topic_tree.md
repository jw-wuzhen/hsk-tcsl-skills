# HSK 话题树

结构：**一级话题 > 二级话题 > 三级话题**。生成任何材料前，先把用户话题定位到树上某一支（等级 > 一级 > 二级 > 三级），再按该位置展开内容。话题不属于该等级时，先说明话题在哪个等级出现，再决定降级或标注。

## HSK1

### 基本信息
- **个人信息**：姓名、国籍、年龄、性别、喜好、习惯等；身份、家庭成员、朋友、技能等
- **事件信息**：日期、时间、地点、方位、参加者、号码等
- **物品信息**：物品名称；物品特征
- **环境信息**：天气；环境特点

### 日常生活
- **交往**：基本礼貌行为；简单互动行为；意愿感受
- **饮食**：食物饮品；就餐
- **交通出行**：问路；出行方式；出行安排
- **购物**：商品名称；商品价格；商品选购
- **医疗健康**：生病、看病、探病等
- **休闲**：休闲活动

### 教育情况
- **学习情况**：课程信息；学习内容；教育层次
- **校园生活**：学校情况；课后活动

### 职场生活
- **工作情况**：工作信息；工作评价
- **职业**：职业种类

### 文化与传统
- **饮食文化**：中餐；传统饮品

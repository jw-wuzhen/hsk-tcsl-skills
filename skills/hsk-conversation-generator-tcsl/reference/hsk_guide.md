# HSK 分级简化指南（写作/改写专用）

本指南用于分级简化与等级控制。等级词汇口径以本技能 reference/ 下的 2026 版 HSK 分级词表（hsk_lookup.py 可查）为准；下表词语对照为教学常用参考，拿不准的词按「宁降不升」处理。

## 一、各级语言边界

### HSK1（150 词）
- 只用最基本日常词：我/你/他、吃、喝、看、买、去、是、有、很、都、也。
- 句式：主谓宾单句，≤8 字。**写作场景基本不用**（产出过于生硬），仅当用户明确要求时使用。

### HSK2（300 词）
- 加入：时候、天气、考试、觉得、帮助、一起、为什么、怎么。
- 句式：可加「…的时候」「因为…所以」简单版，≤14 字。

### HSK3（600 词）
- 词汇：已经、但是、如果、还是、意思、告诉、发现、影响（名）、健康、环境（生活语境）。
- 句式：简单复句——因为…所以 / 先…再 / 又…又 / 一边…一边。
- **禁用**：成语、把字句复杂用法、被动句（被/让/叫）、长定语（「我昨天在学校图书馆借的那本很有意思的书」这类）。

### HSK4（1200 词）
- 词汇：虽然、不但…而且、无论、反而、印象、丰富、精彩、深刻、经验、态度、效果、原因。
- 句式：常用复句、越来越、既…又…、形容词+极了。
- **禁用**：文言残留（亦/愈/之/其）、「随着…的发展」这类抽象框架（HSK5）、多层嵌套复句。

### HSK5（2500 词）
- 词汇：沟通、交流、体现、反映、概念、矛盾、耐心、谦虚、浪费、效率、责任、重视。
- 句式：多层复句、常见书面语——随着 / 因此 / 通过 / 面对 / 对…来说。
- **禁用**：文言词（倘若/倘若/乃至/亦/愈加）、双重否定嵌套（「不能不承认…未必不是」）、欧化长定语。

### HSK6（5000 词）
- 词汇：广泛运用书面语、四字词语适度出现（如：丰富多彩、无可奈何、根深蒂固）。
- 句式：自由。**慎用**：文言词堆砌、超 40 字复句、连环被动。

| 原句式（高） | 降级写法（低） | 适用 |
|---|---|---|

## 四、拆句操作法（简化核心技能）

1. **找拆分点**：优先级 = 关联词处 > 逗号处 > 主语转换处。
2. **每句一个信息点**：谁+做什么 / 什么+怎么样。
3. **补主语**：拆句后每句都要有明确主语，避免指代不清（「他很忙，所以没来」拆后 →「爸爸工作很忙。他没有来参加。」）。
4. **连接词显性化**：拆出的句子用「因为/所以/但是/然后」简单连接，保持逻辑可见。

**示范**（HSK6 → HSK3）：
- 原：「尽管天气预报说今天下午可能会有雷阵雨，但是考虑到 exhibition 开幕式的时间无法更改，我们还是决定按原计划出发。」
- 拆：①今天下午可能下大雨。②展览的开始时间不能改。③所以我们还是按原来的计划出发。
- 说明：拆 3 句；「尽管…但是…」→「…。所以…」；「雷阵雨」→「大雨」；「考虑到」删除；每句 ≤14 字。

## 五、简化质量自检清单

- [ ] 每句字数 ≤ 目标级上限（HSK3:18 / HSK4:22 / HSK5:28 / HSK6:35）
- [ ] 无目标级禁用句式（对照第一节）
- [ ] 无目标级禁用词汇（对照第二节，宁降不升）
- [ ] 原文信息点零丢失（逐条核对）
- [ ] 每句有主语，无指代不清
- [ ] 简化后无新引入的语法错误
- [ ] 专有名词未动，必要时加了括号注释

## 六、常见简化错误（必须避免）

1. **简化即删减**：把「他因为生病没来上课」简化成「他没来上课」——丢了原因，信息损失。
2. **降级不彻底**：换了词但保留「随着…的发展」框架，HSK4 学生仍读不懂。
3. **降级过度**：HSK5 目标却全部改成 HSK3，读起来幼稚，学生学不到东西。目标级词汇该用就用。
4. **拆句失联**：拆出的短句之间没有逻辑连接词，读起来像流水账。
5. **替换造成搭配错误**：「提高效率」简化成「上涨效率」（×）——替换后必须检查搭配。

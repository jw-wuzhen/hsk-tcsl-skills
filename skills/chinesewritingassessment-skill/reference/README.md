# 参考资料目录

本目录用于支撑《chinesewritingassessment-skill》的评估逻辑、错因归因和全文评价。原则上，样例只用于测试；知识来源以权威国际中文教育与考试标准为主。

## 参考资料结构

- `hsk_grammar_standard.md`：HSK 语法标准与分级示例
- `international_chinese_learning_standards.md`：国际中文教育中文水平等级标准与考试资源梳理
- `cefr_overview.md`：CEFR 与中文写作能力对照
- `error_taxonomy.md`：写作错误类型与知识点映射
- `writing_assessment_rubric.md`：篇章写作评分规则

## 权威官方来源

1. HSK / Chinese Testing International
   - https://www.chinesetest.cn/
   - https://www.chinesetest.cn/Development

2. CEFR（Council of Europe）
   - https://coe.int/en/web/common-european-framework-reference-languages

3. ACTFL Guidelines
   - https://www.actfl.org/resources/guidelines-and-manuals/actfl-proficiency-guidelines-2012

4. 国际中文教育相关标准与教材体系
   - 以中国官方中文教育与考试大纲、国际中文教学语法教材、教学规范为主

## 使用原则

- 评估必须解释“为什么错”而不是只给出判定。
- 词汇和语法知识要与 HSK 与 CEFR 目标相衔接。
- 错误类型要可追踪到对应知识点，便于教师复盘和学生自学。
- 真实范文与标准只是测试样例，不替代官方教学标准。

# 中文写作评估量表（诊断性写作测试评分量表）

> **量表依据**：史剑雄、王佶旻《诊断性写作测试评分量表的构建研究》，《语言文字应用》2022年第3期，第114-123页。
> 本文本为论文评分量表的完整落地方案。论文通过探索性因素分析（KMO=0.871，累计解释64.097%总方差）将22条描述语划分为4个评分维度，并经多面Rasch模型与评分员访谈检验效度。

## 1. 量表来源与效度证据

| 检验项目 | 结果 | 结论 |
|---|---|---|
| 探索性因素分析 | 4个公因子特征值>1，累计解释64.097%总方差 | 四维度划分合理 |
| 学生层面（Rasch） | 分隔指数3.63，分隔信度0.93，卡方1203.4（p=0.000） | 量表能有效区分学生写作能力 |
| 评分员内在一致性 | 3位评分员 infit∈[0.89,1.13]，outfit∈[0.87,1.17] | 评分员使用量表时一致性良好 |
| 量表层面（Rasch） | 分隔指数2.41（>2），分隔信度0.85，卡方274（p=0.000） | 各维度难度存在显著差异 |
| 维度难度排序 | 写作规范性(0.33) > 语言准确性(0.30) > 篇章合理性(-0.27) > 语言丰富性(-0.36) | 评分员对前两维度更严厉 |
| 访谈反馈 | 完整性、清晰度、可操作性均获评分员肯定 | 量表可用于诊断性写作测试 |

## 2. 四个评分维度与22条描述语

| 维度 | 描述语 | 描述语数量 |
|---|---|---|
| **语言准确性** | 用词准确；语法正确；句子结构正确；句意明确；固定搭配正确 | 5 |
| **语言丰富性** | 能够使用复杂的句式；能正确使用成语、歇后语等熟语；衔接手段多样；词汇丰富多样；议论/描写充分；修辞方法使用得当 | 6 |
| **篇章合理性** | 结构清晰；中心/观点明确；段落过渡自然；段落分配合理；句间衔接自然；内容切题 | 6 |
| **写作规范性** | 汉字书写正确；字数符合要求；格式规范；卷面整洁；字迹清晰 | 5 |

## 3. 各维度4级评分量表（论文表3）

### 3.1 语言准确性（Linguistic Accuracy）

| 等级 | 描述 |
|---|---|
| 4（优秀） | 词语、句子结构、固定搭配、语法等完全正确；语言表述清晰，无歧义 |
| 3（良好） | 词语、句子结构、固定搭配、语法等基本正确；表达基本清晰，个别句子理解不畅 |
| 2（一般） | 词语、句子结构、固定搭配、语法等有一些错误；文章存在多处不顺畅 |
| 1（极差） | 词语、句子结构、固定搭配、语法等错误很多；表达非常不清晰，难以理解 |

### 3.2 语言丰富性（Linguistic Richness）

| 等级 | 描述 |
|---|---|
| 4（优秀） | 词汇丰富多样；能使用复杂句式，句式灵活富有变化；能灵活使用成语、歇后语和修辞方法加强表达效果；熟练使用多种关联词；论据具体丰富，有扎实的论点 |
| 3（良好） | 词汇、句式较为丰富；能准确使用基本的衔接手段和关联词；能较为详细地论证论点 |
| 2（一般） | 词汇、句式略显单薄；能尝试使用基本的修辞手段和关联词进行作文；能就论点展开简单地说明 |
| 1（极差） | 词汇、句式极其简单、单调；不能有效使用熟语和修辞手法进行写作；不能有效使用衔接手法进行阐述；无法论证论点 |

### 3.3 篇章合理性（Discourse Rationality）

| 等级 | 描述 |
|---|---|
| 4（优秀） | 结构清晰，段落详略得当；句间、段落间衔接自然、得体；内容切合主题；主题、思想表达完整鲜明 |
| 3（良好） | 结构基本清晰，段落安排基本合理；文章衔接基本连贯；内容切合主题；思想表达基本清晰 |
| 2（一般） | 文章有一定的结构逻辑性；表达连贯性稍差；内容基本切合主题；能有效进行观点表达 |
| 1（极差） | 结构混乱，层次不清；文章连接不紧密；内容与主题无关；表达观点困难 |

### 3.4 写作规范性（Writing Normalization）

| 等级 | 描述 |
|---|---|
| 4（优秀） | 格式符合规范；汉字书写正确；卷面整洁、字迹清晰（纸笔考试）；排版、页面布局美观（机考）；篇幅达到规定字数 |
| 3（良好） | 格式有少量错误；汉字书写存在少量错误；卷面比较整洁、字迹比较清晰（纸笔考试）；排版、页面布局较为合理（机考）；篇幅基本达到要求 |
| 2（一般） | 格式问题严重；有一些错别字；基本做到卷面整洁、字迹清晰（纸笔考试）；排版、页面布局合理（机考）；篇幅基本达到要求 |
| 1（极差） | 格式不规范；汉字书写存在大量错误；卷面不整洁、字迹潦草难辨（纸笔考试）；排版、页面布局十分随意、不美观（机考）；字数完全不达标 |

## 4. 自动化评分规则（脚本实现）

`assess_essay.py` 将上述量表量化为可解释的规则，各维度映射到 1-4 级：

| 维度 | 量化依据 | 映射规则（节选） |
|---|---|---|
| 语言准确性 | 错误密度（确定错误+可能错误×0.5）/句数，按目标等级调整严格度 | ≤0.15→4；≤0.45→3；≤0.90→2；否则→1 |
| 语言丰富性 | HSK5/6+词汇占比、平均句长、逻辑关联词数量 | 高占比且句长≥15且关联词≥3→4；… |
| 篇章合理性 | 段落数、逻辑关联词数、信息量（正文长度） | 综合得分≥3→4；≥2→3；≥1→2；否则→1 |
| 写作规范性 | 篇幅达标率（对目标等级建议字数）、用词/重复类错误数 | 达标100%且无该类错误→4；≥80%→3；≥50%→2；否则→1 |

**总分**：四维度等权平均换算百分制（`round(平均等级 × 25)`）。论文未指定各维度权重，故采用等权；论文实证表明各维度难度排序为写作规范性 > 语言准确性 > 篇章合理性 > 语言丰富性，评分时可在说明中呈现该排序。

**目标等级建议篇幅**（产品可配置参数，非论文数据）：HSK1-6 依次为 80/120/160/200/250/300 字。

## 5. 评分流程

1. 先判断作文是否完成写作任务、是否切题。
2. 依据规则库定位语言错误 → 计算「语言准确性」等级。
3. 分析词汇等级分布、句式与衔接 → 计算「语言丰富性」等级。
4. 检查段落结构、逻辑关联词 → 计算「篇章合理性」等级。
5. 检查篇幅、格式与用词错误 → 计算「写作规范性」等级。
6. 输出四维度 1-4 级 + 百分制总分 + 各维度论文等级描述语 + 改进建议。

# CEFR 与中文写作评估对照

## 1. 目标

CEFR（Common European Framework of Reference for Languages）提供了语言能力的国际化描述框架。对于中文写作评估，CEFR 可以帮助我们判断：

- 文章是否符合目标语言能力水平
- 错误是否属于低级别语言学习者的典型现象
- 学生能否在特定阶段完成明确的写作任务

## 2. CEFR 的写作维度

CEFR 通常从以下角度描述写作能力：

- 内容完成度：是否完成题目要求
- 语言准确性：是否能够正确使用基本语法和词汇
- 组织结构：是否能写出清晰段落和逻辑顺序
- 语用适切：是否适合特定语境和语体

## 3. 典型阶段划分

### A1-A2：基础表达

- 能写简单句子和短句
- 能描述个人信息、日常生活、基本活动
- 常见问题：主谓结构不完整、词汇过于简单、逻辑重复

### B1：独立表达

- 能写简短段落，表达事件和感受
- 能写出基本原因、结果和时间顺序
- 常见问题：句子不够完备、连接词使用单一、语义联系弱

### B2：较成熟表达

- 能写完整短文，表达观点和理由
- 能组织段落并保持较强逻辑
- 常见问题：长句过多、搭配错误、篇章过于机械

### C1：复杂表达

- 能写成熟、层次清晰、论证充分的文章
- 能使用更复杂的语法和逻辑连接
- 常见问题：语气过于书面、句法复杂但不稳定、概念表达略显僵硬

## 4. 与中文写作评估的连接

写作评估时，可将 CEFR 维度映射到中文评估标准：

| CEFR 维度 | 中文写作观察点 |
|---|---|
| 内容完成度 | 是否回答题目、是否有中心思想 |
| 语言控制 | 语法、词汇、搭配是否稳定 |
| 连贯性 | 句间衔接、段落组织、逻辑顺序 |
| 语域适切 | 是否符合较正式或日常语境 |

## 5. 评估建议

- 对留学生写作，应同时看“语言准确性”和“篇章完成度”。
- 不要把“复杂句式”当成“更高级”的唯一标准。
- 真正高级的是：表达清晰、结构合理、逻辑稳定、语体恰当。

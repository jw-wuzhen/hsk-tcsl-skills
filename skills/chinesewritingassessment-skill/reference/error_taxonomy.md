# 中文写作错误类型表（用于自动定位与归因）

## 1. 目标

该文件用于指导“语法/语义错误定位”模块如何进行分类，并为“错题归因报告自动生成”提供知识点基础。

## 2. 错误类别

### 2.1 语法错误

- 主谓不一致
- 句法结构不完整
- 词序偏差
- 虚词错误：在、了、的、地、得、把、被等
- 句式使用不当

典型例子：
- 他昨天去学校了很多朋友。
- 我喜欢的书很有意思的。

### 2.2 搭配错误

- 动宾搭配不自然
- 形容词与名词不匹配
- 介词搭配错误
- 固定表达误用

典型例子：
- 做一个很大学习。
- 有很大的影响力的人。

### 2.3 语义错误

- 词义不准确
- 语义重复
- 逻辑语义冲突
- 语境不合适

典型例子：
- 这个问题很解决。
- 他非常高兴地哭了很多次。

### 2.4 用词错误

- 近义词误用
- 语体错位
- 词性误用
- 过度泛化

典型例子：
- 我想学习中文的环境很好。
- 这件事情让我很困难。

### 2.5 逻辑问题

- 因果关系混乱
- 转折顺序不合理
- 时间顺序不清
- 论证跳跃

典型例子：
- 因为下雨，所以我去公园。
- 先上课，然后我吃饭。

### 2.6 篇章与语用问题

- 段落中中心思想不清
- 信息重复、无层次
- 衔接词使用机械
- 语体不符合写作任务

## 3. 归因维度

每类错误都可以归因于以下某一层：

- 词汇层
- 语法层
- 语义层
- 逻辑层
- 篇章层
- 语用层

## 4. 评估时的判定建议

- 如果仅是局部句法问题：优先归到语法层
- 如果是多句之间的逻辑不通：归到逻辑层或篇章层
- 如果是“表达得不自然但不算错”：归到语用层
- 如果是几个词的搭配错：归到词汇/搭配层

## 5. 输出格式建议

评估时输出应至少包含：

- 错误类型
- 句子/段落位置
- 具体问题说明
- 归因层级
- 改正建议
- 对应知识点

## 6. 对应知识点示例

| 错误类型 | 可能对应知识点 |
|---|---|
| 动宾搭配错误 | 固定搭配、动词用法、虚词结构 |
| 介词误用 | 介词短语、格局结构 |
| 因果逻辑混乱 | 因果复句、语义衔接 |
| 时间顺序不合理 | 时间状语、叙述逻辑 |
| 句法不完整 | 主谓宾结构、定状补结构 |

## 7. 使用原则

该错误类型表不是“机械判错表”，而是“教学诊断框架”。它要求系统在判定错误后明确说明：

- 错误属于什么类别
- 是什么层面的问题
- 应该回到哪一类知识点复习

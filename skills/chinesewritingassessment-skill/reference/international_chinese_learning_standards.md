# 国际中文教育中文水平等级标准与写作评估参考

## 1. 目标

本参考用于支撑“国际中文教育中文水平等级标准”与“写作评估”之间的映射关系，帮助技能在以下场景中形成稳定评估逻辑：

- 留学生中文作文诊断
- 语法/语义错误定位
- 错题归因基于标准知识点
- 全文评价与学习建议

## 3. 等级定位建议

国际中文教育通常将语言能力与写作表现分层，中文写作能力可与 HSK 和 CEFR 进行对照参考：

| HSK 等级 | 对应写作能力 | 典型写作任务 |
|---|---|---|
| HSK 1-2 | 能写简单句与短句 | 自我介绍、日常记录、简单表达 |
| HSK 3 | 能写简短段落 | 生活事件、感受表达、简单描写 |
| HSK 4 | 能写结构基本完整的短文 | 说明原因、表达观点、描述经历 |
| HSK 5 | 能写较完整篇章 | 议论、说明、比较与论述 |
| HSK 6 | 能写成熟篇章，表达较复杂观点 | 论证型、评论型、学术型写作 |

## 4. 写作能力的核心观察点

从语言发展角度，写作评价通常关注：

1. 语法准确性
   - 句法结构是否完整
   - 词语搭配是否自然
   - 虚词、助词、语气词使用是否正确

2. 语义清晰度
   - 语意是否完整
   - 逻辑关系是否明确
   - 含义是否符合语境

3. 篇章连贯性
   - 段落是否有逻辑顺序
   - 句与句之间是否自然过渡
   - 主题是否保持稳定

4. 语言表达丰富度
   - 词汇是否有效
   - 句式是否多样
   - 表达是否符合语体要求

## 5. 语法与写作的联动关系

为避免“只看错句、不看知识点”，评估要将错误纳入以下教学结构：

- 词汇层：词义、搭配、固定结构
- 句法层：主谓结构、宾语、定语/状语/补语
- 语义层：逻辑关系、信息传递、语境理解
- 篇章层：连贯、论证、段落组织

因此，写作评估不应只看“是否正确”，还要看“错在哪里，为什么错，怎样学会避免”。

## 6. 评估建议

- 写作指标要结合 HSK 明确的语法范围与词汇范围。
- 评价过程要同时参考 CEFR 的语用能力水平。
- 学习诊断报告应能够为教师提供复盘素材，也可以帮助学生建立学习计划。

## 7. 本技能的应用原则

本技能采用的原则是：

- 以教学事实为主，而不是抽象语言判断
- 以标准与教材为主，而不是单一样例
- 以错误归因为主，而不是“只提示错误”
- 以写作提升建议为主，而不是纯粹得分

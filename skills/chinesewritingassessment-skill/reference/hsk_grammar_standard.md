# HSK 语法标准与写作分级参考

## 1. 资料定位

本文件用于给写作评估系统提供分级语法参考，帮助将作文中的语言问题对应到 HSK 语法学习范围。

官方参考入口：

- HSK 官方站：https://www.chinesetest.cn/
- HSK 相关发展与标准信息：https://www.chinesetest.cn/Development

## 2. HSK 1-6 语法发展主线

### HSK 1

核心目标：掌握最基础的句型和句法结构。

典型内容：
- 主语 + 谓语
- 主语 + 谓语 + 宾语
- 是字句
- 有字句
- 基本时间、地点、数量表达
- 一般疑问句、特指疑问句

### HSK 2

核心目标：能表达简单动作、状态与原因。

典型内容：
- 能愿动词：会、能、可以、要、想
- 动态助词：了、着、过
- 趋向补语：来、去、上来、下去
- 比较表达：比、跟……一样
- 简单因果复句：因为……所以……

### HSK 3

核心目标：能表达较完整事件，并使用基本复句。

典型内容：
- 把字句
- 被字句
- 状态补语
- 可能补语
- 因果、并列、承接句式
- 常见固定搭配

### HSK 4

核心目标：能写结构比较完整的短文。

典型内容：
- 复杂定语与状语
- 条件、假设、让步复句
- 逻辑连接词增多
- 书面语表达开始增加

### HSK 5

核心目标：能写较复杂论述和篇章。

典型内容：
- 高级复句
- 复杂关系表达
- 句式多样化
- 书面语言与逻辑表达增强

### HSK 6

核心目标：能写成熟、有层次的文章。

典型内容：
- 高级书面语
- 复杂修辞与语气
- 学术性文本与论证结构
- 多层论证、篇章组织和逻辑把控

## 3. 常见错误与 HSK 关联示例

| 错误类型 | 常见表现 | 典型知识点 |
|---|---|---|
| 语法结构错误 | 主谓不一致；缺少宾语；语序异常 | 基本句型、谓语结构、定语/状语位置 |
| 搭配错误 | 动宾不搭；介词误用；固定结构误用 | 固定搭配、虚词、介词结构 |
| 时态/体问题 | 语义时间不一致 | 了、过、着、在、将来时句式 |
| 逻辑连接错误 | 因果混乱；转折不合理 | 因果复句、转折复句、过渡句 |
| 语义不清 | 一个句子里信息过多、指代不清 | 指代、信息组织、语义衔接 |
| 语体不合适 | 口语表达硬塞进书面语 | 语体、表达层级、书面语规范 |

## 4. 评估时的使用方式

评估时，不应只看“这个句子看起来不自然”，而要进一步判断：

- 该错误属于哪个 HS K 语法层级？
- 该问题反映的是词语、句法还是篇章问题？
- 是否属于该等级学习者在此阶段最常见的错误？

这能帮助系统输出更有教学意义的反馈。

## 5. 建议的层级判断规则

- 若错误属于最基础的主谓、虚词、句型问题，归为 HSK 1-3 级基础问题。
- 若错误常见于复杂复句、逻辑连接、书面语表达，则归为 HSK 4-6 级高级问题。
- 若问题是表达太口语、结构混乱、逻辑跳跃，则优先归到篇章与语用层而非单纯词汇错误。

## 6. 使用目标

本标准用于：

- 对作文错误进行 HSK 分层归因
- 判断写作是否符合目标等级的语言能力要求
- 设计个性化提升建议和复盘任务

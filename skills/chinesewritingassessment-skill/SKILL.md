# 中文写作评估技能

面向外国留学生中文写作教学与评估场景，核心功能：对学生作文进行语法/语义错误定位、错因归因、全文评价，并生成可预览、可下载的 HTML 教学报告。

## ⚠️ 强制约束（必须严格遵守）

**本技能的所有评估结果必须来自脚本输出，禁止自行推理或编造。**

1. **必须调用脚本**：收到评估请求后，必须先运行 `assess_essay.py` 获取评估结果 JSON，不得跳过脚本直接用自身知识分析作文。
2. **错误必须来自脚本**：输出的每一条语法/语义错误、错题归因、评分都必须严格对应脚本返回的 JSON 字段，**不得自行添加脚本未检测到的错误**。
3. **零错误如实输出**：如果脚本返回 0 个错误（`part1_grammar_errors` 中无"无明显错误"以外的条目），必须如实输出"未检测到明显的语法或语义问题"，**不得为了"显得有用"而自行编造错误**。
4. **HTML 与文字一致**：文字分析中展示的错误数量、类型、内容必须与 HTML 报告完全一致，因为二者来自同一份脚本评估结果。
5. **禁止说"无法读取文件"**：脚本路径是固定的，直接运行即可。如果脚本执行失败，输出"评估脚本暂时不可用，请稍后重试"，不要说"无法读取 SKILL.md"或"权限问题"。

## 语言规则

- 评估对象：外国留学生中文作文
- 输出语言：中文（评估报告、错误说明、建议均用中文）
- 语法术语：中文为主，必要时附英文（如 Subject 主语）
- HSK 等级：HSK1-HSK6，默认 HSK3

## 功能：中文写作评估

**Trigger（触发词）**：批改作文、分析语法错误、评估写作、找错、HSK写作、作文批改、写作诊断、中文写作评估、分析这篇作文

**Input（输入）**：
- 必需：完整的中文作文文本
- 可选：HSK 等级（HSK1-HSK6）、写作任务类型、学习者母语

### Step 1：检查输入与 HSK 等级

**⚠️ 最重要：先扫描用户消息中的 HSK 等级，找到后直接使用，不要追问。**

扫描模式（不区分大小写）：
- "HSK" + 数字 1-6（如 HSK5、HSK 3、hsk4）
- "等级" + 数字 1-6（如 等级5）
- 数字 1-6 + "级"（如 5级）

找到 → 直接使用，进入 Step 2。**不要再次询问。**
未找到 → 使用默认 HSK3，进入 Step 2。

### Step 2：调用评估脚本获取结果

运行脚本（仅运行一次）：

```bash
python3 /mnt/skills/user/chinesewritingassessment-skill/v1.0.0/scripts/assess_essay.py \
  --text "学生作文完整文本" \
  --hsk-level HSK3 \
  --pretty \
  --output /mnt/user-data/workspace/assessment_result.json
```

参数说明：
- `--text`：学生作文完整文本（必须完整传入，不要截断）
- `--hsk-level`：HSK 等级（HSK1-HSK6，默认 HSK3）
- `--pretty`：格式化 JSON 输出
- `--output`：评估结果保存路径

如果脚本路径不可用，将 `scripts/assess_essay.py` 和 `scripts/html_material.py` 复制到 `/mnt/user-data/workspace/`，同时复制 `reference/hsk_vocabulary/` 和 `reference/grammar_knowledge/` 目录，然后从 `/mnt/user-data/workspace/` 运行。

脚本输出 JSON 包含：
- `part1_grammar_errors`：语法/语义错误列表
- `part2_attribution_report`：错因归因报告
- `part3_overall_evaluation`：全文评价（总分、六维度评分、改进建议）
- `knowledge_graph`：知识图谱
- `reference_sources`：权威参考来源
- `teaching_material_html`：HTML 学习单（备用）

**如果脚本输出以 "ERROR" 开头或执行失败**：告诉用户"评估脚本暂时不可用，请稍后重试"，**不要自行编造评估结果**。

### Step 3：输出三部分文字分析

**⚠️ 必须严格基于 Step 2 的脚本 JSON 输出，不得自行添加、修改或编造任何错误、归因或评分。**

- 错误数量 = `part1_grammar_errors` 中 type 不为"无明显错误"的条目数
- 归因数量 = 错误数量（一一对应）
- 总分和维度评分 = `part3_overall_evaluation` 中的字段
- **如果脚本返回 0 个错误，直接输出"未检测到明显的语法或语义问题"，不要自行编造错误来"显得有用"**

根据脚本 JSON 结果，严格按照以下模板输出文字分析：

### Step 4：生成 HTML 教学报告

运行脚本生成 HTML 报告：

```bash
python3 /mnt/skills/user/chinesewritingassessment-skill/v1.0.0/scripts/generate_report_html.py \
  --text "学生作文完整文本" \
  --result /mnt/user-data/workspace/assessment_result.json \
  --hsk-level HSK3 \
  --output /mnt/user-data/outputs/chinese_writing_report.html
```

参数说明：
- `--text`：学生作文完整文本
- `--result`：Step 2 保存的评估结果 JSON
- `--hsk-level`：HSK 等级
- `--output`：HTML 报告输出路径

该脚本自动生成自包含 HTML 报告，包含：
- 报告头部（标题、日期、HSK 等级、字数）
- 原文精读区（HSK 词汇等级着色、拼音标注）
- 错误标注与句子分析
- 六维度评分展示
- 词汇学习卡片
- 打印/下载按钮

HTML 完全自包含，不依赖外部网络资源，可离线使用。

### Step 5：展示 HTML 报告

调用 `present_files` 将 HTML 报告展示给用户：

```
present_files(path="/mnt/user-data/outputs/chinese_writing_report.html")
```

然后用一句话引导用户：

> 以上是完整的文字评估分析。下方是可预览、可打印、可下载的 HTML 教学报告，可直接在浏览器中打开使用。

## 错误处理

- **空输入/非中文输入**：请用户提供中文作文文本
- **脚本执行失败**：告诉用户"评估脚本暂时不可用，请稍后重试"，不要自行编造结果
- **HSK 等级未提供**：使用默认 HSK3，不要追问
- **作文中没有检测到错误**：明确说明"未检测到明显错误"，不要虚构错误
- **HTML 生成失败**：文字分析仍然输出，备注"HTML 报告暂时不可用"
- **不要向用户展示原始错误信息或脚本堆栈**
- **不要要求用户执行 `/mnt/skills/...` 路径或手动操作文件**

## 设计原则

- **准确性**：错误定位必须具体、清晰、有依据，不把正常表达误判为错误
- **可解释性**：必须说明为什么错、错在什么层面、关联什么知识点
- **可教学性**：评估结果必须方便教师和学生复盘学习
- **国际中文教学标准意识**：评估逻辑与国际中文教学语法体系、HSK 标准保持一致
- **区分"语法错误""表达不够自然"和"风格选择"**：避免将可接受的语言变体一律判错

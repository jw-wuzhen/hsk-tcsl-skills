# HSK 写作题目生成器 — TCSL 版 v2.0

## 一、这个技能是什么

面向**国际中文教师与学习者**的 HSK 写作教学材料生成器，基于 2026 年 7 月实施的新版 HSK 考试大纲（2026 版分级词表与话题树）。

用户只需一句话（如"HSK4 旅行作文"），即输出一整套写作练习材料：

1. **写作题目** —— 题型提示语 + 字数要求 + 具体任务
2. **构思辅助** —— 构思引导问题、可用句型、参考关键词
3. **参考范文** —— 按目标等级级控撰写，生词标注并附拼音/词性/释义/例句
4. **HTML 学习页**（核心交付物）—— 学生练习版 + 教师备课版双视图，自包含、可打印/下载，模拟日常作文纸书写场景

覆盖 HSK1-6 全部写作题型；任意话题均可处理（话题树定位，不在树内自动映射到最接近分支）。

## 二、适用场景与触发

| 场景 | 用户示例 | 产出 |
|---|---|---|
| 写作题目生成 | "出个HSK4的作文题"、"帮我布置作业" | 题目 + 构思引导 + 句型 + 关键词 |
| 参考范文 | "给一篇HSK5范文"、"例文" | 范文（级控、生词标注）+ 生词表 |
| 完整练习材料（**默认路径**） | "HSK4旅行作文"、"备考模拟练习" | 题目 + 范文 + HTML 学习页 |
| 看图作文 | "HSK5看图作文" | 四格漫画图 + 看图作文全套材料 |
| 教师备课 | "帮我做备课材料" | 教师视图全部内容（大纲依据/结构/评分/建议） |

**Trigger 词**：写作题目、作文题、写作文、练习题、布置作业、出一个题、范文、参考作文、例文、model essay、sample essay、essay topic、practice、homework、writing task

**Input**：`hsk_level`（必填，可从消息中扫描） + `exam_type`（选填） + `topic`（选填） + `native_language`（选填）

## 四、完整工作流（一次调用）

推荐路径：**题目 + 范文 + HTML 一步到位**。仅当用户明确"只要题目"时才停在 Step 4。

### Step 1 — 确定 HSK 等级（最先做，找到就不再问）

扫描用户消息（不区分大小写）：
- `"HSK" + 数字 1-6`（如 HSK6、HSK 3、hsk4）
- `"等级" + 数字 1-6`（如 等级5）
- `数字 1-6 + "级"`（如 6级）
- `"level" + 数字 1-6`（如 level3）

找到 → 直接使用，进入 Step 2。**绝不再问。**
没找到 → 问 "What is your HSK level?"

### Step 2 — 确定题型

- 用户明确说了题型 → 使用
- 没说明 → 按该等级默认题型：

| 等级 | 默认题型 (exam_type) | 最少字数 | 题目特征 |
|------|----------------------|----------|----------|
| HSK1-3 | 基础书写练习 `sentence_practice` | 写汉字/词语/1-3句话 | 抄写、填写基本信息、简单介绍 |
| HSK4 | 短文写作 `short_essay` | 80 | 介绍人/事/物，讲述一次经历 |
| HSK5 | 看图作文 `picture_story` | 100 | 根据四格图写完整故事 |
| HSK5 | 引语作文 `quote_essay` | 200 | 根据名言/俗语写，结合经历谈理解 |
| HSK6 | 应用文 `practical_writing` | 150 | 通知、启事、邀请信、邮件、说明书 |
| HSK6 | 议论文 `argumentative` | 300 | 对争议话题表达观点、论证 |

- 用户指定的题型与该等级不符（如"HSK4的议论文"）→ 礼貌说明该等级可选题型，推荐最接近的一种，不硬生成

### Step 3 — 话题定位（任意话题都支持）

1. 读取 `<skill_root>/reference/topic_tree.md`，把用户话题定位到树上：等级 > 一级 > 二级 > 三级
2. 话题在树内 → 按原话题生成
3. **话题不在树内**（如"野外露营"、"国际贸易"）→ 不报错！选择话题树中最接近的一支，题目围绕该支展开；教师视图注明"话题已映射到：XX（原话题：XX）"。低等级学生遇到高等级话题（如 HSK4 被要求写"人工智能"）→ 改写为贴近该等级生活的场景（如"用手机学中文"）
4. 用户没给话题 → 从该等级话题树中选一个高频话题（或随机）

### Step 4 — 组装题目

读取 `<skill_root>/reference/writing_guide.md` 第二节，按题型模板组装：
- 题目 = 题型提示语 + 字数要求 + 具体任务
- 参考关键词 5-8 个（本等级词汇）
- 构思引导问题 3-4 个（本等级句式：HSK1-2 "你什么时候……？"，HSK4-5 "你觉得……怎么样？"，HSK6 "有人认为……，你怎么看？"）
- 可用句型 2-3 条（本等级语法点）

按"输出模板 · 学生视图"输出题目部分。

> 若用户要参考范文/完整练习材料（常见默认需求），继续 Step 5-7。

### Step 5 — 撰写参考范文

**Mode A — 推荐范文库**：话题命中范文库 → 读取 `<skill_root>/reference/model_essays/<type>.md`（如 `hsk4.md`、`hsk5_picture.md`），按话题/引语/文体选最接近的一篇。

**Mode B — 现场新写**：话题未命中范文库、或用户明确要新内容 → 按以下规则写：
1. 先读 `<skill_root>/reference/writing_guide.md` 第三、四节，确定该等级写作能力与语法边界
2. 参照 `<skill_root>/reference/model_essays/<type>.md` 中同题型范文的结构与风格
3. 用本等级词汇书写（拿不准的词查 `hsk_lookup.py`，见 Step 6）
4. 按题型结构组织：短文=开头-主体-结尾；看图=四格图推进；引语=理解-经历-点题；应用文=文体格式（通知/启事有标题+正文+落款，邮件有称呼+正文+署名）；议论文=观点-理由-例子-结论

**范文必须：① 起一个贴合话题的标题；② 正文分成 3-4 个自然段**（每段一个中心意思），不要整篇写成一段。

**语法检查与修正**（输出前必做，修正后只输出修正版，不展示原始错误）：
- 错别字、的/地/得混用、标点错误
- 残缺句、语序偏误、关联词残缺（虽然……**但是**……）
- 口语书面语混用、欧化句式（"被"字滥用、名词化堆叠）
- 成语/文言词与等级不符

### Step 6 — 级控检查与生词标注

1. 从范文中挑出 10-20 个最没把握的词（高级动词、形容词、抽象名词）以及所有准备标注的词
2. 运行查词脚本：
   ```bash
   python3 <skill_root>/scripts/hsk_lookup.py --words "词1,词2,..."
   ```
3. 处理规则（**生词 = 目标等级及以上词汇**；如用户指定 HSK5，则 HSK5/HSK6/HSK7-9 级词及词表查不到的词均为生词）：
   - 词的等级 < 学生等级 → 正常使用（已学词汇）
   - 词的等级 ≥ 学生等级，或词表查不到 → 视为**生词**：正文中标注（见"五 · 页面特性"），并列入【生词表】给出 拼音 + 词性 + 释义 + 原文例句（词性标注时给出，没有可留空；例句留空时脚本自动从范文提取）
   - 结构助词（了/呢/吗/吧/啊）和标点跳过
4. 句长检查：HSK1 ≤8字、HSK2 ≤14字、HSK3 ≤18字、HSK4 ≤22字、HSK5 ≤28字、HSK6 ≤35字。不确定时可运行：
   ```bash
   python3 <skill_root>/scripts/text_stats.py --text "<范文>" --level hsk4
   ```

### Step 7 — 生成 HTML 学习页（强制步骤，自动完成）

**⚠️ 不要手工给句子中的词加注（会导致 token 溢出），不要自己写 HTML——把范文文本交给脚本生成。**

1. 把**修正后的范文**保存为 `/mnt/user-data/workspace/essay_text.txt`：
   - **第一行 = 标题**（贴合话题，不加书名号）
   - **其后每一行 = 一个自然段**（3-4 段，开头-主体-结尾；不加"图1/图2"等标注，图序信息写进 teacher.json 的 `structure` 字段）
   - 渲染时标题自动居中、正文每段首行自动空两格，模拟日常作文书写格式

2. 把**重点词句**（5-8 个，**必须是范文正文中实际出现的表达**）保存为 `/mnt/user-data/workspace/expr.json`：
   ```json
   [{"expression":"真是","pinyin":"zhēn shì","hsk":7,"en_def":"really; indeed","explanation":"","example":"你真是个懂礼貌的好孩子。"}]
   ```
   - `example` 填范文中包含该表达的原句（含省略号的表达如"虽然……但是……"也能自动匹配）；**留空则脚本自动从范文提取**
   - **重点词句必须实际出现在范文正文**：未在正文出现的表达，学习页会自动整行隐藏（不再展示警告行），请勿收录范文外的词句

3. 把教师元数据保存为 `/mnt/user-data/workspace/teacher.json`：
   ```json
   {
     "exam_name":"看图作文","exam_type":"picture_story","topic":"公交让座",
     "level_label":"HSK 5","min_chars":100,"time_limit":"25分钟",
     "question":"根据下面四格漫画写一篇作文，不少于100字。",
     "guiding_questions":["图上都有谁？","发生了什么事？","结果怎么样？"],
     "patterns":["……的时候，……","虽然……但是……"],"connectors":["首先","然后","最后"],
     "keywords":["让座","老人","礼貌","帮助"],
     "requirements":["字数不少于100字","结构：开头-主体-结尾"],
     "teaching_info":[["等级","HSK 5（CEFR B1）"],["考试题型","看图作文（≥100字）"],["大纲写作能力","…"],["话题树位置","社会交往 > 公共交通 > 让座"]],
     "structure":"图1（车上人多找座）→ 图2（老奶奶上车没座）→ 图3（小明让座）→ 图4（大家点赞，小明开心）",
     "rubric":["内容完整（四图要素齐全）","语言准确（本级词汇语法）","结构清晰（起因-经过-结果）"],
     "teaching_tips":["先让学生看漫画编故事，再给范文","★生词先讲解再让学生读"],
     "exam_note":"HSK5 看图作文要求…",
     "glossary":[{"word":"真是","pinyin":"zhēn shì","pos":"adv.","meaning":"really; indeed","example":"你真是个懂礼貌的好孩子。"}],
     "out_of_syllabus_note":"生词 x 个（HSKx 及以上词汇及大纲外词）"
   }
   ```
   - 缺字段没问题（脚本会跳过空卡片），但题目、题型、字数、结构、评分要点等核心字段务必填
   - **⚠️ 生词表一致性（必守）：`glossary` 只收范文中实际出现、且正文已标注的词**，逐一对齐；严禁收录范文中没有的词

4. 运行渲染脚本：
   ```bash
   python3 <skill_root>/scripts/render_essay_html.py \
     --essay-file /mnt/user-data/workspace/essay_text.txt \
     --expressions-json /mnt/user-data/workspace/expr.json \
     --teacher-json /mnt/user-data/workspace/teacher.json \
     --output /mnt/user-data/outputs/essay_话题_HSKx.html \
     --hsk-level 5 --title "标题"
   ```
   - 脚本自动按 2026 词表分段、标注每个词的 HSK 等级与拼音、高亮重点词句、标注生词并与生词表对齐
   - 看图作文**必须嵌入漫画**（三选一）：`--comic-images`（4 张分图）/ `--comic-image`（单张 2×2）/ `--comic-svg`（本地保底）
   - 脚本路径不可用时：把 `render_essay_html.py` 复制到 `/mnt/user-data/workspace/`，并把 `reference/` 下的 `hsk_vocab.json`、`char_pinyin.json` 一起复制为 `/mnt/user-data/workspace/reference/`（保持 scripts 与 reference 的上下级关系），从工作区运行

5. 用 `present_files` 把 HTML 展示给用户（文本视图也照常输出）
6. HTML 生成失败时：文本视图照常输出，注明"HTML 学习页暂不可用"。**绝不编造 HTML 内容，绝不展示原始报错信息。**

## 五、HTML 学习页详解（核心交付物）

脚本产出**自包含单文件**（内联 CSS/JS，无外网依赖），包含：

**双视图**
- **学生练习版**：写作题目、四格漫画（看图作文时）、构思引导、可用句型、参考关键词、写作要求
- **教师备课版**：教学信息（等级/题型/字数/时间/大纲依据/话题树位置）、参考范文（书写纸切换）、生词表、范文结构、评分要点、教学建议、级控自动检查、考试说明

**参考范文 · 三种书写纸模式**（模拟日常作文纸，一键切换）
- **普通**：正文每段首行空两格，楷体书写
- **横线纸**：横线跟随每行字（行距即线距，完全自适应）
- **方格纸**：字帖米字格（每格十字+对角线虚线，8 部分），**固定网格每行满格**（末行空格补齐），段落开头空两格

**词汇标注与学习辅助**
- 每个词按 HSK 等级着色（1-6 级色卡图例），悬停显示拼音+等级
- **生词（目标等级及以上 + 词表查不到）**：正文中橙底虚线样式标注，悬停显示拼音/词性/释义；图例含"生词（大纲外）"色标
- **重点词句表**：只展示范文正文实际出现的表达，原文例句高亮加粗；未出现的自动隐藏，底部给一行浅色提示（便于调用方自查配置）
- **生词表**：单星号 ★ 前缀、内联流式排列，每项含拼音/词性/释义/原文例句
- 顶部按钮：🖨 打印/存为 PDF、⬇ 下载 HTML

**级控自动检查**：按正文实算字数（不含标题），标注达标/未达标。

## 六、看图作文四格漫画（**必出图片**）

看图作文（picture_story）的核心特色是**四格漫画图片**——任何情况下都必须产出一张图片交付，绝不只输出文字画面描述。

### Step 1 — 设计四格故事（文本）

按话题设计：图1（遇到/开始）→ 图2-3（发展/冲突/帮助）→ 图4（结果）。每格填写以下字段，存为 `/mnt/user-data/workspace/panels.json`：

| 字段 | 说明 | 示例 |
|---|---|---|
| `scene` | 场景 | 学校操场、公交车上、公园…… |
| `props` | 场景标志物（**必填 2-3 个可画物体**） | "车窗、扶手、双排座椅" |
| `characters` | 人物 | 李明、同学们…… |
| `look` | 主角外貌（**四格共用同一描述**，保证人物一致） | "穿红色短袖T恤、黑色短发、圆脸的男孩" |
| `action` | 动作（**只写一个核心瞬间、一个动词短语**，一眼能看懂；不要写一连串动作） | "小明指着靠窗的空座位，正要坐下" |
| `mood` | 情绪 | 开心/难过/着急…… |
| `detail` | 画面细节（可选，每格 1 个） | "膝盖擦破，坐在地上" |
| `dialogue` | 台词（可选，1 句，短） | "加油！" |

```json
[
  {"scene":"学校操场","props":"跑道、观众席、彩旗","characters":"李明、同学们","look":"穿红色短袖T恤、黑色短发、圆脸的男孩","action":"运动会上李明跑在最前面","mood":"开心","dialogue":"加油！","detail":"他回头看向身后"},
  {"scene":"操场跑道","props":"红色跑道、白线","characters":"李明","action":"李明不小心摔倒了","mood":"难过","detail":"膝盖擦破，坐在地上"},
  {"scene":"操场","props":"跑道、草坪","characters":"同学们","action":"两个同学赶紧跑过来把李明扶起来","mood":"关心","detail":"一人扶一边，表情担心"},
  {"scene":"终点","props":"终点线、彩带","characters":"李明、同学们","action":"大家一起手拉手跑向终点","mood":"开心","detail":"一起冲过终点线，阳光明媚"}
]
```

**连贯性要求**：四格围绕**同一主角**，情节因果连贯（起因→发展→结果）；动作具体、可画出来（谁+做什么+关键细节），避免抽象词。
**场景人物结合**（看图作文的画面核心）：每格让读者一眼看清"在哪里、谁、在做什么"——场景占画面重要部分（全景/中景，人物全身或大半身），标志物清晰可辨（公交车要有车窗扶手、公园要有树和长椅）。

### Step 2 — 生成漫画图片（两级路径，至少产出一张）

**路径①（首选）— 平台图像生成工具**：用平台主模型自带的图像生成能力（如 image_gen），把四格画面描述生成卡通四格漫画。四格共用同一主角外貌（读 `look` 字段），画面禁止出现文字（标牌留白）。

**路径②（保底，必成功）— 本地脚本**（零网络、零密钥）：
```bash
python3 <skill_root>/scripts/comic_render.py \
  --panels-json /mnt/user-data/workspace/panels.json \
  --output /mnt/user-data/outputs/comic_话题.svg --title "话题"
```

**可选增强 — 千问通义万相**（画质更好，不配置密钥不影响主流程）：若已配置密钥（环境变量 `DASHSCOPE_API_KEY`/`QWEN_API_KEY`、调用参数 `--api-key`，或技能包根目录 `api_key.txt`），可运行 `comic_gen.py` 优先生成 PNG 四格漫画（`--mode panels` 逐格 4 张、`--mode single` 一张 2×2），再按 Step 3 嵌入 HTML。

**规则**：按 ①→② 依次尝试；②失败（几乎不可能，纯本地）→ 才允许输出文字画面描述并注明"漫画生成失败"。**任何情况下至少交付一张图片。**

### Step 3 — 嵌入与交付

1. 漫画图**一律嵌入 HTML 学习页**（HTML 是主交付物，图在其中）：
   - 4 张分图：`--comic-images comic_话题_p1.png,...,comic_话题_p4.png`（2×2 网格嵌入）
   - 单张 2×2 图：`--comic-image /mnt/user-data/outputs/comic_话题.png`
   - 本地 SVG：`--comic-svg /mnt/user-data/outputs/comic_话题.svg`
2. 交付顺序：先用 `present_files` 交付 HTML（图已嵌入）；漫画 PNG 可再单独交付一次（方便学生保存原图）
3. 范文必须覆盖四张图的情节推进（对照 Step 5 Mode B 第 4 条）

## 八、通用级控规则

1. **词汇边界与生词定义**：**生词 = 目标等级及以上词汇**（如用户指定 HSK5，则 HSK5、HSK6、HSK7-9 级词汇及词表查不到的词均为生词；杜绝把更低等级词汇误收入生词表）。范文正文以目标等级**以下**词汇为主体书写（HSK5 范文尽量用 HSK1-4），不可避免用到生词时一律标注并列入【生词表】；拿不准用 `hsk_lookup.py` 查，查不到即按生词处理（宁标勿漏）
2. **语法边界**：只用该等级及以下语法点（见 writing_guide.md 第四节）；HSK3 以下不用把字句/被字句，HSK4 以下不用"随着…的发展"类书面框架
3. **字数达标**：正文达到题型最少字数
4. **结构完整**：按题型结构组织

## 九、Language Rules

Target users: English-speaking Chinese learners (international students).
- 中文文本、拼音、中文释义：保持中文
- 语法/教学术语：英文（括号附中文），如 Subject (主语)
- 题目、引导问题、句型、关键词、范文正文：中文
- 解释、建议、提示、评分要点：英文（用户要求中文或 `feedback_language=zh` 时用中文）
- 询问等级："What is your HSK level?"

## 十、Error Handling

- 输入为空或非中文：用英文请用户给中文
- 没找到等级：问 "What is your HSK level?"
- 脚本失败/词表缺失：不阻塞输出，范文照常给出（生词按"宁标勿漏"人工判断），并提示"词汇核查暂不可用"
- 话题不在话题树：映射到最接近的话题支，不报错（见 Step 3）
- 用户要求改写/润色已有作文：这是"作文批改"需求，本技能不覆盖，礼貌告知（或引导到其他技能）
- HTML 生成失败：文本视图照常输出，注明"HTML 学习页暂不可用"；绝不编造 HTML、绝不展示原始报错（见 Step 7）
- 绝不向用户展示原始报错信息
